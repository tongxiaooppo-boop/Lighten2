# 給 Sonnet：使用說明更新（日期切換、這餐不吃、飲料分組與收合）

一律用中文。這份是獨立任務，不需要讀其他交接檔。**只改 `docs/使用說明.html` 一個檔案，不要改程式，不要 commit。** 改完由 Opus 在手機寬度（360px）驗收。

## 背景
`docs/使用說明.html` 是 App「輕盈計畫」的分頁版使用說明（跟 App 一樣的分頁與子分頁）。2026-10-02 上線了下面這些改動，說明書還沒寫。

## 要補的內容（用字照 App 畫面上的字）
1. **今日建議的日期列**（放在今日建議分頁的開頭說明）：最上面一排七個日子（「今天」＋未來 6 天，例「週六 10/03」）。點未來的日子：沒有推薦、沒有彙總卡，只有每一餐「還沒排」＋「自己選」（開著的時段還有「這餐不吃」）；上面一行「已排 N 餐，約 X kcal」。有預約的日子底下有一個小點。
2. **排預約**：未來日子的「自己選」→ 標題「排進 10/03（週六）：晚餐」、按鈕「排進預約」→ 選法跟平常一樣（聚餐可用外食分頁的「找不到？直接估算」），下面寫「預約不計算配額」。排好的卡片可以「改」「取消預約」。也可以預約「這餐不吃」（例：明天早上要空腹抽血）。
3. **到了那一天**：預約的卡片寫「預約 · 約 N kcal」，按「記下」才算吃過（App 不會自動當你吃了）；也可以「改」「取消預約」。其他餐的建議會先扣掉預約的熱量；彙總卡的大數字不扣預約，下面多一行「已排：晚餐 約 1200 kcal」。如果其他餐的配額因為預約變很少，卡片會寫「晚餐已經排進來了，這餐照平常吃就好」——意思是照平常吃，不用為了聚餐少吃。預約的東西之後被你標了不吃或刪掉，卡片會寫原因，那一餐改回建議。
4. **這餐不吃**：今天每一餐的卡片下面有「這餐不吃」，按了記成 0 大卡（卡片寫「這餐沒吃」，可以撤銷），其他餐的配額會變多。基本資料關掉的時段（下午茶、宵夜預設關）沒有這個按鈕。為什麼要記：一天每個開著的時段都有紀錄，才算「完整的一天」，體重校正比較準；但**不確定有沒有吃就不要按**。
5. **「自己選」的現成飲料分組**：分「超商」「手搖飲・咖啡・早餐店」「我的品項」三組；超商分頁超商那組在最上面、外食與自煮分頁手搖飲那組在最上面。
6. **清單收合**：超商、外食分頁的每個分類（例：健身餐盒、沙拉）預設收起來，標題寫筆數，點一下打開；「常吃」組和「已選」照樣打開；現成飲料只打開目前分頁那組。關掉「自己選」再打開回到預設。
7. 「還沒做、之後會有」可以一句帶過：隔天的「昨天的餐」確認卡片、「補記過去的一餐」還在做。

## 寫法規則
- 照現有說明書的段落、標題層級、class 寫法（先讀整份，模仿最接近的段落，例如「自己選」詳細說明那幾個 subpane）。
- **頁內連結注意**：頁面的分頁切換程式會攔截 `#xxx` 連結，只能用「分頁名稱開頭」的 hash（看檔案裡現有的連結怎麼寫，照抄格式）；不確定就不要加連結。
- 不寫評判的字：不要出現「漏記」「忘了記」「沒記到」「還沒記」「未完成」「吃太多」「罪惡」「爆卡」。
- 短句、中文標點；一段只講一件事。
