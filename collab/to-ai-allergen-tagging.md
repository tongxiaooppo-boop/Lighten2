# 給 AI 助手（Sonnet／Cline／Gemini 都可以）：食物代換表 374 個品名的過敏原與素食標註

一律用中文回覆。這份是獨立任務說明，不需要讀其他交接檔。

## 背景

專案是一個個人減脂飲食 App。App 要用衛福部國健署《食物代換表》的品項讓使用者挑食材。App 有「過敏原」與「全素／蛋奶素」的硬性過濾：**沒有標註的品項一律當成「未確認」，有設過敏原或素食的使用者會看到它被擋掉**。所以每個品名都需要標註。

你的標註是**初稿**，之後由另一位審核者（扮演資深營養師）逐筆核對後才會進 App。你的工作是把每一筆標好、把理由寫清楚、把拿不準的明確標出來，**不是**直接定案。

## 輸入

`collab/transcripts/exchange_names.tsv`（UTF-8，每行一個品名，Tab 分隔）：

```
key	大類	子類	品名	原列文字
附-3-1#21#1	豆魚蛋肉類	家禽	雞里肉	雞里肉、雞胸肉
```

- `key` 在你交回的結果裡**原樣使用**，不要改。
- 品名前面的 ＊、◎、△、# 是代換表的註記符號（例如 ＊ 代表含碳水化合物、◎ 代表膽固醇含量），**不是**過敏原符號，忽略即可。
- 共 374 行（不含開頭 4 行註解）。每一行都要有結果，不能漏。

**如果你讀不到檔案**（例如網頁版 AI），請使用者把這個 tsv 檔的內容貼給你。檔案太長的話可以分批，每批照同樣的格式交回。

## 標註規則（App 章程 B6，必須遵守）

### 過敏原：只能用這 11 個詞

`甲殼類`、`軟體動物`、`魚`、`蛋`、`乳製品`、`花生`、`堅果`、`麩質`、`黃豆`、`芝麻`，以及 `未確認`

- **甲殼類**：蝦、蟹、蝦米、蝦皮。
- **軟體動物**：蚵（牡蠣）、花枝、章魚、小卷、魷魚、貝類（文蛤、蛤蜊）。
- **花生和堅果分開**（台灣法規如此）：花生只標 `花生`，不標 `堅果`。
- **麩質**包含小麥、大麥、黑麥、**燕麥**（台灣過敏原標示規定）。名稱含「燕麥」的一律要有 `麩質`。麵筋、麵腸、烤麩是小麥麩質做的，要標 `麩質`，**不是**黃豆。
- **黃豆**包含毛豆、黑豆（黑豆是黃豆的一種）、豆腐、豆干、豆漿、豆皮、味噌。**紅豆、綠豆、花豆、鷹嘴豆、豌豆不是黃豆**，不標。
- **不含任何過敏原**時填空陣列 `[]`，表示「確認不含」。只有**單一原料、成分明確**的天然食材可以這樣填，例如白米、高麗菜、蘋果、雞胸肉。

### 什麼時候要標 `未確認`

- **複合加工品一律含 `未確認`**：成分不只一樣、而且配方依廠牌而定的東西，例如魚丸、貢丸、甜不辣、火腿、培根、肉鬆、素雞、素火腿、麵包、餅乾、油條、蘿蔔糕、蛋餅皮、沖泡包。你可以**另外**把「很可能含的」過敏原列在 `likely`，但 `allergen_tags` 裡一定要有 `未確認`。
- **拿不準的也標 `未確認`**。原則是**往保守方向標**：寧可標「未確認」讓使用者自己確認，也不要把可能有過敏原的東西標成「確認不含」。這是安全問題。
- 名稱太籠統、看不出是什麼的（例如「一般魚類」這種泛稱，其實可以確定是 `魚`），能確定的就標，確定不了的標 `未確認`。

### 全素、蛋奶素

- `vegan`（全素）：**只有完全沒有動物成分，而且過敏原不是 `未確認`** 的才標 `true`。含蛋、乳製品、魚、甲殼類、軟體動物、肉的一律 `false`。
- `lacto_ovo`（蛋奶素）：可以有蛋和乳製品，不能有肉、魚、海鮮。全素的東西蛋奶素也是 `true`。
- **過敏原含 `未確認` 的加工品**（例如素雞、素火腿），`vegan` 一律填 `false`。`lacto_ovo` 除非你有具體依據（例如這類產品在台灣法規下必須標示素食種類），否則也填 `false`，並把依據寫在 `reason`。
- 注意過敏原詞彙裡**沒有**「肉」：雞、豬、牛、羊、內臟、豬血等沒有對應的過敏原，`allergen_tags` 可以是 `[]`，但 `vegan`、`lacto_ovo` 必須是 `false`。
- 蜂蜜、動物油（豬油、牛油）、奶油：不是素（奶油是乳製品，蛋奶素可以；豬油、牛油兩者都不行）。

## 輸出

寫成 `collab/transcripts/exchange_tags.json`（UTF-8）：

```json
{
  "_by": "你的模型名稱，例如 Claude Sonnet / Gemini 2.5 Pro",
  "_date": "2026-MM-DD",
  "items": [
    {
      "key": "附-3-1#21#1",
      "name": "雞里肉",
      "allergen_tags": [],
      "likely": [],
      "vegan": false,
      "lacto_ovo": false,
      "confidence": "high",
      "reason": "單一原料雞肉；過敏原詞彙沒有禽肉，所以是空陣列；是肉所以不是素。"
    },
    {
      "key": "附-3-2#4#2",
      "name": "花枝丸(+7公克碳水化合物)",
      "allergen_tags": ["軟體動物", "未確認"],
      "likely": ["魚", "麩質", "黃豆", "蛋"],
      "vegan": false,
      "lacto_ovo": false,
      "confidence": "medium",
      "reason": "複合加工品，主成分花枝（軟體動物）；常見配方含魚漿、澱粉、可能含蛋白與黃豆蛋白，依廠牌而異，所以加未確認。"
    }
  ]
}
```

欄位說明：
- `allergen_tags`：只能用上面 11 個詞。確定含的都列出來；複合加工品或拿不準的要加 `未確認`。
- `likely`：選填。只給複合加工品用，列出「很可能含、但依廠牌而定」的過敏原，給審核者參考，不會直接進 App。
- `confidence`：`high`（單一原料、沒有疑問）、`medium`（有判斷成分）、`low`（不確定這是什麼東西，或地區叫法不同）。
- `reason`：每一筆都要寫，一兩句話，說明判斷依據。`low` 的要寫出你不確定的地方。

**如果你能執行程式**（Sonnet、Cline）：交件前寫一支小腳本自我檢查，確認：
1. `items` 共 374 筆，key 跟 tsv 一一對應，沒有漏、沒有多、沒有重複；
2. `allergen_tags` 和 `likely` 只用上面 11 個詞；
3. `vegan: true` 的，`allergen_tags` 沒有蛋、乳製品、魚、甲殼類、軟體動物、未確認；
4. `lacto_ovo: true` 的，沒有魚、甲殼類、軟體動物；`vegan: true` 的 `lacto_ovo` 也是 `true`；
5. 名稱含「燕麥」的有 `麩質`。

## 交付

1. 結果寫進 `collab/transcripts/exchange_tags.json`。**不要動**其他檔案（`data/`、`js/`、`docs/`、`tools/` 都不能碰）。
2. 在 `collab/transcripts/exchange_tags_report.md` 寫一份短報告：
   - `confidence` 為 `low` 的清單（key、品名、不確定什麼）；
   - 你覺得代換表名稱有歧義、需要營養師判斷的地方（例如「角菜」「龍鬚菜」在不同地區指不同的菜）；
   - 自我檢查的結果（如果有跑）。
3. 能用 git 的話，可以 commit 到 master，訊息例如 `collab: 代換表 374 品名的過敏原與素食標註初稿`，結尾加 `Co-Authored-By: <你的模型名稱>`。pre-commit hook 約 8 秒，**禁止 `--no-verify`**。**不要 push**。
4. 網頁版 AI 不能寫檔的話，直接在回覆裡輸出完整 JSON 和報告，由使用者存檔。
