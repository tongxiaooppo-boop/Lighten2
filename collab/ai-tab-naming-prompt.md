# 給其他 AI 的命名提案請求（輕盈計畫 App 分頁改名）

把下面這段貼給別的 AI（GPT/Gemini/DeepSeek 都可以），請它幫忙想分頁名稱。

```
我在做一個中文減重/健身飲食記錄的手機網頁 App，叫「輕盈計畫」。有 4 個分頁，
分頁按鈕文字目前是：「基本資料」「今日建議」「大餐預約」「本週總覽」（每個都是 4 個字，
按鈕空間有限，新名字也請盡量控制在 3–5 個中文字之間，超過就會被截斷或換行）。

我要重新命名第三個分頁，暫定名稱是「大餐預約」，這個分頁目前的內容是：
1. 使用者可以「預約」未來某一餐要吃大餐（選日期/時段/餐點或估算份量），或「直接記錄」已經吃掉的大餐。
2. 可以確認/取消預約。
3. 頁面上方會顯示「近7天平均攝取熱量 vs 每日目標」這個中性的統計數字（不是進度條、不是額度制）。

命名上有幾個硬性限制（這個App的產品原則）：
- 絕對不能用「額度」「剩餘」「超支」「彈性點數」「扣點」「補償」「贖罪」這類字眼，
  因為App的核心理念是不把吃大餐當成需要之後彌補或懲罰的事，也不用遊戲化點數制造成心理負擔。
- 不要用「作弊餐」「欺騙餐」「罪惡感」這類負面框架的詞（就算是很多健身App常用的「cheat meal」翻譯過來的說法也不要）。
- 語氣要中性、輕鬆，不要聽起來像在管理/審核使用者的行為，比較像「幫你規劃」而不是「盯著你」。
- 名稱本身不用強調「熱量」兩個字（熱量資訊本來就會顯示在頁面內容裡，分頁名稱不用重複）。

請給我 8–10 個候選名稱，每個都用一句話講為什麼適合（例如語感、跟其他分頁名稱的一致性、
會不會被誤解成別的功能）。可以往「規劃」「安排」「餐次」「彈性但不踩到彈性點數語感」
這些方向想，也歡迎完全跳脫這些方向的提案。
```

## 我自己先想的候選（給你參考，AI 的建議回來後可以合併看）

| 名稱 | 想法 |
|---|---|
| 大餐預約 | 目前暫定名，最直白，跟功能本身（預約表單）完全對應，但只涵蓋「預約」沒涵蓋「近7天平均」那塊內容 |
| 大餐計畫 | 「計畫」比「預約」更寬，也能涵蓋「直接記錄」跟總覽數字，語氣中性 |
| 大餐安排 | 跟「大餐計畫」類似，「安排」比「計畫」更輕、更口語 |
| 餐次規劃 | 不特別聚焦「大餐」，比較像是通用的餐次管理，但可能讓人以為跟「今日建議」重複 |
| 特別餐次 | 迴避「大餐」這個詞本身可能帶的份量感/罪惡感聯想，但「特別」有點抽象，第一次看到不一定懂在幹嘛 |
| 大餐紀錄 | 偏向「記錄」而非「預約」，跟現有「直接記錄」功能語感一致，但可能讓人以為只能事後補記 |

我自己傾向「大餐計畫」或「大餐安排」，比「大餐預約」涵蓋範圍更完整，但都還在「大餐」這個詞上，沒有完全跳脫；如果你想要更中性、不強調「大餐」的方向，「特別餐次」是我想到比較好的備案。最終還是你決定，不用照我的偏好選。
