# 給 Cline：衛福部全表剩下 1895 筆的過敏原與素食標註

一律用中文回覆。這份是獨立任務說明，不需要讀其他交接檔。

## 背景

專案是個人減脂飲食 App。App 對過敏原、全素／蛋奶素有硬性過濾：**沒有標註的品項一律當成「未確認」**。食物代換表 374 個品名（對應衛福部全表 2213 筆裡的 318 筆）已經標完、審過（`collab/transcripts/exchange_tags.json`），規則跟範例都在 `collab/to-ai-allergen-tagging.md`，**先讀那份**，標註規則（過敏原 11 個詞、`未確認` 的判斷、全素／蛋奶素規則）完全沿用，這份不重複寫一次。

這次要做的是**剩下沒被代換表用到的 1895 筆**（衛福部全表 2213 筆扣掉代換表已對應的 318 筆），目的是之後「我的食材」功能（使用者從衛福部全表自己挑食材）也要有過敏原／素食標註可以用。

你的標註一樣是**初稿**，之後由使用者請 Claude Sonnet 複查一遍，不是直接定案。

## 輸入

`collab/transcripts/tfda_remaining.tsv`（UTF-8，Tab 分隔，已經幫你從衛福部全表扣掉代換表已覆蓋的 318 筆，共 **1895 行**，不含表頭）：

```
整合編號	食品分類	樣品名稱	內容物描述	俗名
A0100101	穀物類	大麥仁	樣品狀態:生,已去殼; 前處理描述:混合均勻磨碎	小薏仁,洋薏仁,珍珠薏仁
```

- `整合編號`（衛福部原始編號）在你交回的結果裡**原樣使用**，不要改，這是後續比對的 key。
- `內容物描述` 常常寫了生熟、加工方式，判斷過敏原與素食時要看它，不要只看樣品名稱（例如「樣品狀態:熟」「已調味」這種字樣會影響判斷）。
- `食品分類` 是衛福部自己的大類（跟 App 的分層大類不是同一套，只當參考）。

## 標註規則

完全比照 `collab/to-ai-allergen-tagging.md` 的「標註規則」一節：
- 過敏原只能用這 11 個詞：`甲殼類`、`軟體動物`、`魚`、`蛋`、`乳製品`、`花生`、`堅果`、`麩質`、`黃豆`、`芝麻`、`未確認`。
- 複合加工品、拿不準的一律含 `未確認`，往保守方向標。
- `vegan`／`lacto_ovo` 規則同上，過敏原含 `未確認` 的一律 `vegan: false`。

**額外要注意**（這份資料跟代換表不同的地方）：
- 衛福部樣品很多是**單一原料、生鮮或簡單前處理**（例如「大麥仁，生，已去殼」），這種比代換表的加工食品好判斷，可以放心給 `high` 信心與空陣列過敏原。
- 也有不少是**加工／調理食品**（beverages、醬料、零食、預拌粉、即食品），這些照代換表的規則走保守路線，標 `未確認`。
- 如果樣品名稱/描述是**非食物**（例如純營養補充錠、非供人食用的樣品、飼料），標 `未確認`，`reason` 寫清楚「不是一般食物，過敏原無法判斷」，不要自己排除這筆——**1895 筆每一筆都要有結果，不能刪減**。
- 有些品項其實就是代換表品項的**不同型態**（例如同一食材的生／熟、不同部位），不用刻意去查代換表有沒有类似的，直接照這筆自己的內容物描述判斷就好。

## 輸出

寫成 `collab/transcripts/tfda_tags.json`（UTF-8），格式跟代換表那份一致，只是 `key` 換成整合編號：

```json
{
  "_by": "Cline（模型名稱）",
  "_date": "2026-MM-DD",
  "items": [
    {
      "key": "A0100101",
      "name": "大麥仁",
      "allergen_tags": ["麩質"],
      "likely": [],
      "vegan": true,
      "lacto_ovo": true,
      "confidence": "high",
      "reason": "大麥為麩質穀物；單一原料生鮮穀物，無動物成分。"
    }
  ]
}
```

欄位定義、`likely`／`confidence`／`reason` 的寫法都跟 `to-ai-allergen-tagging.md` 一樣。

**交件前寫一支小腳本自我檢查，確認：**
1. `items` 共 **1895 筆**，key 跟 `tfda_remaining.tsv` 一一對應，沒有漏、沒有多、沒有重複；
2. `allergen_tags` 和 `likely` 只用上面 11 個詞；
3. `vegan: true` 的，`allergen_tags` 沒有蛋、乳製品、魚、甲殼類、軟體動物、未確認；
4. `lacto_ovo: true` 的，沒有魚、甲殼類、軟體動物；`vegan: true` 的 `lacto_ovo` 也是 `true`；
5. 名稱或內容物描述含「燕麥」的有 `麩質`。
