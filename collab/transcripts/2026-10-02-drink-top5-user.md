# 使用者提供的隨餐飲料排行（2026-10-02，使用者貼上，來源是別的 AI 的回答，排名未查證）

用途：檢查資料庫有沒有這些飲料的營養資料，沒有的要調查補上。排名本身不採用（未查證），只當「常見飲料清單」。

## 1. 超商熱銷隨餐（不限時段）
1. 統一 陽光高纖豆漿（無糖／低糖）
2. 原萃 綠茶／烏龍茶
3. 純喫茶 檸檬紅茶／鮮柚綠茶
4. 麥香 紅茶／奶茶
5. 超商現煮 拿鐵／美式咖啡

## 2. 傳統早餐
1. 大冰奶（早餐店奶茶）
2. 傳統現磨豆漿（清漿）／米漿
3. 研磨黑咖啡／風味拿鐵
4. 紅茶（古早味／阿薩姆）
5. 鮮奶茶（小農／紅茶拿鐵）

## 3. 傳統午餐
1. 無糖綠茶／青茶
2. 古早味冬瓜茶
3. 冰鎮紅茶
4. 酸梅湯／烏梅汁
5. 可口可樂

## 4. 點心下午茶
1. 珍珠奶茶
2. 檸檬紅茶／鮮桔茶
3. 梅子綠茶／多多綠茶
4. 風味果茶（百香雙響炮、水果茶）
5. 冰淇淋紅茶

## 5. 晚餐
1. 炭焙烏龍茶／鐵觀音
2. 可爾必思／乳酸飲料
3. 可口可樂／雪碧
4. 芭樂柳橙汁
5. 愛之味麥仔茶

## 6. 宵夜
1. 冰豆漿／米漿
2. 可口可樂／碳酸飲料
3. 無糖綠茶（手搖或寶特瓶）
4. 冬瓜檸檬
5. 氣泡水（檸檬／原味）
