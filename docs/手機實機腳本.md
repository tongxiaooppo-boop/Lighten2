## 0. 開啟

1. 用手機開正式網址 https://tongxiaooppo-boop.github.io/Lighten2/ （GitHub Pages，master 根目錄，推送後約 1 分鐘更新）→ 頁面正常顯示，上方分頁是「基本資料／今日建議／我的食物／本週總覽／運動紀錄」五個（沒有美饗日曆、沒有採買清單，decisions #96），一排等寬放得下、不用左右滑；較窄的手機（360 寬）也一樣。
1a. 還沒填基本資料時切到「我的食物」→ 可以瀏覽、點開明細；「不吃」按鈕是淡色不能按，旁邊寫「先在基本資料填好身體數據並按計算，才能標「常吃」「不吃」。」
2. 部署新版本後重新打開（不手動清快取）→ 看到的是新版本（import map 版本字串，章程 C1.6）。GitHub Pages 讓首頁暫存最多 10 分鐘（`Cache-Control: max-age=600`），推送後 10 分鐘內可能還是舊版；超過 10 分鐘還是舊版才算問題。辨認方法：這次看上方分頁有沒有「我的食物」。

## 1. 基本資料

1. 填年齡、性別、身高、體重、活動量、目標模式，按「計算」→ 計算結果出現；體重趨勢校正卡片顯示「公式目標／校正值／目前每日目標」。
2. 過敏原勾選框、「今日建議時段與來源」下拉都點得到，按鈕高度夠手指點（≥ 44px）。
3. 「今日體重回填」送出 → 顯示「已記錄 日期 體重 kg」。
4. 過敏原勾選框有 11 個（含「軟體動物」「花生」「芒果」）；飲食型態下拉沒有「低碳」，另有「低碳」勾選框與「家裡用油習慣：一般／少油」下拉；勾選、改選後按「計算」，重新整理再回來，設定還在（−1b）。

## 2. 今日建議

1. 切到今日建議 → 上方彙總卡顯示接下來幾餐的建議熱量；各時段有推薦卡片；關閉的時段顯示「已設定不需要這個時段的建議」。
2. 按「記錄這餐」→ 該時段變成「已記錄：…（約 N kcal）」＋「撤銷」；彙總卡的熱量與蛋白質跟著變。
3. 按「撤銷」→ 該時段回到推薦卡片。
4. 按「倒讚」→ 該時段換一個推薦。
5. 按「順便不要」的晶片 → 該食材/品項從推薦中消失，上方寫「已標不吃「…」，可以在「我的食物」取消。」；接著在基本資料按「計算」，那一項還在（基本資料已經沒有「不吃的食材」區塊）；到「我的食物」最下面「你標了不吃的全部」看得到它；是食材（雞胸肉、青花菜這類）的，「自煮」子分頁下面的「你標了不吃」也有它；按「取消不吃」後就不見。
6. 記下推薦卡片上的組合，切到別的分頁再切回來 → 推薦跟剛才一樣，沒有整批換掉（−1b，decisions #39）。
7. 按「記錄這餐」記早餐 → 午餐、晚餐的推薦不變，而且不會出現剛才早餐吃的同一個品項。
8. 自煮的推薦卡片（煎、炒）的基準熱量後面有「含用油約 Ng」；基本資料改成「少油」後，數字減半。推薦到溫沙拉時，括號裡還有「未含沙拉醬」。
8a. 每張推薦卡片的圖都是該時段的插畫（早餐、午餐…各一張），不會出現雞胸肉、豆腐這類食材照片（decisions #8）。
9. 彙總卡展開營養明細 → 有「鈉 約 N mg（參考 2400 mg）　飽和脂肪 約 N g」（或「無資料」「部分品項無資料」），沒有顏色或警告。

## 3. 自己選

Phase 0 起是三分頁選擇器：超商｜外食｜自煮；「加飲品・水果」「加點單品」是三個分頁共用的兩步（PRD 第 2、4 節、6.3、13.4；單品見第 8 節）。

1. 在午餐的推薦卡片按「自己選」→ 彈出視窗，停在「超商」分頁（午餐預設偏好是超商）；品項依「主餐 → 配菜 → 點心」分區、區內依分類（健身餐盒、沙拉…）分組，卡片只有名稱和熱量、沒有圖片（decisions #8）；**手機剛打開就看得到「取消」「記下這餐」，不用往下捲**；步驟編號是「1. 選品項」「2. 加飲品・水果（選填）」「3. 加點單品（選填）」連續的。
2. 選一個主餐 → 下方摘要「已選 1 件 · 約 N kcal … · 鈉 …」；午餐可以再選第二個主餐（例：雞胸＋蒸地瓜這類，decisions #41）；選第三個主餐時出現「午餐的主餐最多選 2 個。」。
2a. 早餐只在「加飲品・水果」的現成飲料選「拿鐵咖啡（無糖，大杯）」→ 摘要是「鈉 約 113 mg」；「記下這餐」可以按，記得下來（手動記錄不要求主餐）。
2b. 到基本資料勾任一個過敏原（例：蛋）並按「計算」，再開午餐「自己選」→ 超商分頁頂端寫「灰色的 N 項因你的過敏原／飲食設定不能選。」；整組都不能選的分類收成一行（例：「沙拉（4 項因設定不能選）」），點開後卡片灰掉並寫「成分未確認」；同一組裡能選的排前面、灰的排後面。沒勾過敏原時不會灰。
3. 按「記下這餐」→ 視窗關閉，該時段變成已記錄。
3a. （自動版最後記一筆午餐留著，第 4 節本週總覽要有今天的熱量。）
6. 按「取消」或點視窗外的灰色區域 → 視窗關閉，沒有記錄；再打開，回到預設的分頁（切過分頁但沒送出，不會記住）。
7. 在超商分頁選兩個主餐和一杯飲料，切到「外食」分頁 → 飲料還是選著；摘要下方多一行「超商分頁還有 2 項沒有算進這餐」（送出只算目前分頁＋飲料）；外食分頁有便當、麵食等台式外食，也有連鎖健康餐盒。
8. 基本資料把宵夜的「今日建議時段與來源」設成「自動」並按「計算」→ 宵夜「自己選」停在超商分頁；切到外食選一樣送出，撤銷後再打開 → 停在「外食」分頁（記住這個時段上次送出的型態，PRD 第 4 節）。下午茶也設成「自動」時，下午茶的超商分頁只有少數點心，飲料在下面的「加飲品・水果」。

4. 晚餐按「自己選」→ 停在「自煮」分頁（晚餐預設偏好是開伙），子切換是「開伙」；步驟是「1. 快煮或開伙」「2. 選餐型」（上方一行「只記單品可以不選餐型，直接到下面加點單品。」），選了餐型後依序出現「3. 選食材與烹調法」「4. 用油與調味」（有的話）「5. 份量」，最後是「加飲品・水果」「加點單品」，編號連續不跳號；再點一次已選的餐型就取消。選「溫沙拉」、蛋白質、主食、烹調法 → 摘要「已配好 · 約 N kcal（含用油約 Ng）…· 未含沙拉醬」；換成其他餐型就沒有「未含沙拉醬」；份量滑桿可以拖，摘要跟著變。
4b. 蛋白質可以選 2 個、蔬菜可以選 3 個；選滿後其他選項灰掉寫「最多選 N 個」。
4c. 「煎蛋類」選蛋、烹調法「煎」→ 出現用油「預設（5g，依用油習慣）」「約 2 茶匙（10g）」（預設跟 1 茶匙一樣只列一次，沒有「不用油」）；點「約 2 茶匙」→ 摘要「含用油約 10g」、熱量多約 44 kcal；調味有「清淡／一般」。
4d. 按「記下這餐」→ 晚餐變成已記錄。
5. 早餐「自煮」選「早餐碗」→ 烹調法有「免開火」「微波」可選，兩個都能選、能送出。（「這個食材需要加熱」的防呆目前手機上觸發不到：有免開火的餐型只有早餐碗，它能選的食材都不需加熱；這條規則由 diff-recs 的 `compose/*/no-cook-unsafe` 情境與 check-engine 的假骨架自動測。）
5a. 早餐切到「自煮」、什麼都沒選 → 「記下這餐」不能按，提示「請先選餐型」；只選一杯現成飲料 → 可以按（decisions #122 修正 #45，不再提示到超商或外食分頁）。
9. 自煮分頁先在「開伙」選「烤／舒肥定食」、烹調法「烤／氣炸」，再切到「快煮」→ 鮭魚、去皮雞腿肉這類灰掉寫「快煮不含這個食材」；已選的「烤／氣炸」仍可以點掉；「記下這餐」不能按，提示「快煮不含「烤／氣炸」，請換成開伙或換掉它。」；換成煎就能送出。

10. 午餐切到「外食」分頁 → 最上方「找不到？直接估算」；名稱填「喜宴」、按「L 大餐」→ 下方出現「喜宴（L，約 1200 kcal）×」，摘要約 1200 kcal、「蛋白質 —」，缺口文字有「先記下來，其他餐會自動調整」與「蛋白質：無資料」；按「記下這餐」→ 午餐紀錄是「喜宴」、約 1200 kcal。按「×」可以拿掉這筆估算。
11. 在超商或外食分頁最下面按「＋新增到我的超商/外食品項」→ 表單有名稱、熱量、角色（早午晚預設主餐、下午茶宵夜預設點心）、過敏原（未確認／確認不含／含：），「更多（選填）」裡有蛋白質、碳水、脂肪、纖維、飽和脂肪、鈉；有設全素或蛋奶素時，「這個品項是：全素／蛋奶素／都不是」在表單上，沒設時收在「更多」。填名稱、熱量後按「存成我的品項」→ 「我的品項」那組自動展開，新的一筆已選中，摘要跟著變。
11a. 基本資料勾了過敏原（例：蛋）時，快速新增照預設（過敏原未確認）→ 表單下方預告「以你目前的設定，這樣存會不能選：你設了過敏原「蛋」，過敏原未確認的品項不能選。」（只說明是哪個設定，不會叫你改填「確認不含」）；照樣存的話不會選中，並說明原因。
12. 早餐用快速新增記一筆 1800 kcal（例：「吃到飽早午餐」）→ 午餐、晚餐卡片寫「這個時段的配額已經不多了」，**下面仍有「自己選」**；晚餐按「自己選」選一樣送出 → 晚餐變成已記錄（前面吃多了，這一餐還是記得下來）。「暫無適合的組合」的卡片也有「自己選」。

## 4. 本週總覽、運動紀錄

1. 本週總覽 → 列出本週每一天的熱量；沒有完整記錄的日子時顯示說明文字。
2. 運動紀錄 → 選項目、填分鐘、送出 → 歷史紀錄出現；本週活動量文字更新；運動分頁不出現任何飲食熱量。

## 5. 資料備份（B-3，PRD 11.6）

1. 基本資料分頁最下面有「資料備份」：說明「資料只存在這台裝置的瀏覽器裡…」、「匯出備份」「從備份還原」兩個按鈕。
2. 按「匯出備份」→ 下載 `lighten2-backup-今天日期.json`，下方寫「已下載 …（飲食紀錄 N 筆、體重紀錄 N 筆、我的品項 N 筆）」；**沒有**「這份備份目前無法還原」的提示（出現的話截圖，那是舊格式紀錄，見使用者決定 B）。
3. 匯出之後再記一餐、改體重，然後按「從備份還原」選剛才的檔案 → 出現預覽：基本資料／飲食／體重／運動紀錄／我的品項的「備份檔／目前」筆數與最後日期；「目前有 M/D 匯出這份備份之後新增的紀錄，還原後不會保留」；「還原會取代這台裝置上的所有資料，不是同步」。只有筆數與日期，沒有熱量或運動內容。
4. 目前有資料時，「還原」是淡色不能按；按「先匯出目前的資料」（會再下載一個檔）或勾「目前的資料不需要保留」之後才能按。按「取消」→ 預覽關閉，資料不變。
5. 按「還原」→ 頁面重新載入，剛才記的那一餐、改的體重都不見了，其他跟匯出時一樣。
6. 選一個不是備份的檔案（例：一張照片或文字檔）→ 顯示「這個檔案不能還原：…」，沒有「還原」按鈕。

## 6. 我的品項（B-1a，PRD 10.2、10.4、12.3）

1. 晚餐「自己選」→ 超商分頁選一個主餐 → 品項清單**上方**出現「已選（可以改份量）」：名稱、份量「半份／1 份／×1.5／×2」、「不吃」「複製成我的版本」；每行沒有熱量、晶片不上色。按「×2」→ 下方摘要熱量變兩倍。
2. 選一杯現成飲料 → 「加飲品・水果」步驟裡、選中的那杯下面有份量晶片（單品不用晶片，用步進器，見第 8 節）；按「×2」後切到自煮分頁，飲料的「×2」還看得到；飲料按「不加」再選回同一杯 → 份量回到 1 份。送出 → 晚餐紀錄名稱有「×2」。
3. 已選的內建品項按「不吃」（取代原本的「隱藏」）→ 它移到分頁最下面收起來的「你標了不吃（1）」，卡片灰掉不能點，旁邊有「取消不吃」；上方提示「已標不吃「…」，可以在「我的食物」取消。」＋「復原」；按「復原」→ 回到原本的位置、可以選。
3a. 在選擇器裡把今日建議正在推薦的品項標「不吃」，直接按「取消」關掉 → 今日建議馬上換掉那一項（不用切分頁）。
4. 已選的內建品項改「×2」後按「複製成我的版本」→ 出現表單，預帶名稱、熱量、角色、適合的時段等；把熱量改成 444 → 「存成我的品項」→ 原品項消失，「我的品項」那組展開、新的一筆已選中，摘要約 888 kcal（份量沿用 ×2），說明「已複製成我的版本「…」，並選進這一餐。」
5. 快速新增一筆（過敏原照預設「未確認」）、再快速新增一筆勾「含：蛋」→ 到基本資料勾過敏原「蛋」並**按「計算」**（設定要按計算才會存）→ 回晚餐「自己選」超商分頁，打開「我的品項」：未確認的那筆灰掉、旁邊有「補填」；含蛋的那筆只寫「含過敏原」，**沒有**補填。按「補填」→ 過敏原改「確認不含」→ 存檔 → 那筆可以選且已選中，只有一張卡片。最後把過敏原取消並按「計算」。
6. 「我的食物」超商子分頁的「我的品項（N）」（基本資料已經沒有這個區塊）：新到舊；複製來的寫「從內建複製 · 約 N kcal」；點開 → 明細的出處寫「從內建複製」，並列「內建目前的數值」；按「編輯」出現表單。
7. 勾過敏原「蛋」並按「計算」→ 回「我的食物」：過敏原未確認的那幾筆灰色小字寫「成分未確認」，點開有「補填」；含蛋的那筆寫「含過敏原」、沒有補填。狀態只有灰色文字，不上色。最後取消過敏原並按「計算」。
8. 複製品點開按「刪除」→ 移到下面收起來的「已刪除（N）」，上方提示「原本的內建品項「…」仍是換成你的版本，要用回內建到「已換成我的版本」按「改回內建」。」；打開已刪除、點開那筆按「還原」→ 回到我的品項。（2026-10-02 起「封存」改說「刪除」、「隱藏」改說「換成我的版本」，decisions #134）
9. 「已換成我的版本（N）」→ 按「改回內建」→ 提示「你有一筆從它複製的我的品項「…」」。
10. 「飲品・水果」子分頁按「＋新增到我的飲品・水果品項」→ 表單角色預設「飲料」；填名稱、熱量，改成「外食」「主餐」→ 存檔 → 上方寫「已新增「…」。它在「外食」的我的品項。」

## 7. 我的食物（工作線 D 切片 2，PRD 13）

1. 「我的食物」→ 頂端搜尋框，下面「超商／外食／自煮／飲品・水果」四個子分頁（360 寬也一行、不折行）。超商、外食照「自己選」的分法（主餐／配菜／點心，再依分類）；飲品・水果是「現成飲料」→「家裡的飲品」→「水果」。每一列：名稱、「約 N kcal」，被過敏原或飲食設定擋的灰色並寫原因（含過敏原／成分未確認／飲食限制未確認；代換表的品項是人工確認過的，不符合的寫「不符合你的飲食設定」）。
2. 搜尋打「豆漿」→ 只顯示結果，每筆寫「子分頁 · 分類」與狀態（已隱藏、你標了不吃、已封存）；清空回到子分頁。

7. 「自己選」：我的食材在「加點單品」對應大類的最後一組「我的食材」、「其他食材」，液體在「加飲品・水果」；搜尋找得到。沒設一份的只有克數框（預設 100），有設一份的有「份」「克」。記下的名稱寫實際的量（「鯖魚(生) 150g」，品名已寫（生）的不重複）。有衛福部食材時，選擇器先打開，我的食材隨後補上；載入失敗寫一行，不擋其他東西。
