# 烹調方式、油脂與鈉 — 營養觀點與決策紀錄

日期：2026-09-28
提問（使用者原話）：「烹飪方式, 熱量/油脂/鹽(鈉), 請你就營養師角度提出觀點」
決策（使用者原話）：「我拍板, 照你的建議」

以下是 Opus 當時的回覆內容（依對話原文整理成文件格式，數字與建議未更動），最後一節是拍板後的具體規格。

---

## 1. 結論

1. **油要算進熱量，而且是自煮熱量裡最容易少算的一項。** 三餐各炒一道菜，一天就是 20–30g 油（約 180–270 kcal），相當於 1500 kcal 目標的 12–18%。v1 全部算 0，脂肪欄也跟著嚴重偏低。
2. **烹調方式影響熱量有兩條路：加進多少油，以及食物本身失去多少水分。** 後者就是資料 review 的「生熟標錯」問題。
3. **鈉值得記錄、值得顯示，但現階段不拿去評判或影響推薦。** 外食的鈉資料最不可靠，把估計值包裝成精確數字去干預推薦，弊大於利。
4. **鈉跟這個 App 的核心機制有直接關係：水分造成的體重波動。** 吃一頓很鹹的東西，隔天體重多 0.5–1 kg 很常見，那是水分不是脂肪。

## 2. 油脂

換算基準（食物代換表）：油脂類 1 份 = 5g 油 = 1 茶匙 = 45 kcal。

| 烹調方式 | 一人份大約吃進的油 | 說明 |
|---|---|---|
| 免開火、微波、水煮、清蒸 | 0g | |
| 氣炸、烤箱 | 0–2g | 噴油或刷油才有；肉本身逼出的油不算 |
| 煎（不沾鍋） | 約 5g（1 茶匙） | 煎蛋、歐姆蛋吸油比煎肉排多 |
| 炒（只有蛋白質） | 約 5g | |
| 炒（有蔬菜） | 再加約 5g | 葉菜類吸油最多，一盤炒青菜幾乎把油全吸光 |
| 油炸 | 約食物重量的 5–15%，裹粉更多 | 目前的餐型骨架沒有炸；外食品項的熱量已含油 |

原則：
- 算「吃進去的油」，不是「下鍋的油」。
- 炒的用油量跟蔬菜多寡有關：基礎 5g＋有蔬菜再加 5g。一人份蔬菜總量差不多，不必每多一種菜就多加一次。
- 「自己選」可以讓使用者選用油量，選項用中性說法「約 1 茶匙／約 2 茶匙」，不寫「少油（健康）」。推薦卡片一律用預設值。
- 油的種類先不處理；飽和脂肪先在資料裡記錄，之後再決定要不要顯示。

## 3. 烹調改變的是重量，不是總熱量

- 烤、氣炸、煎會失水，同樣 100g 熟雞胸比生的熱量高約三成，但整塊肉的總熱量沒變。
- 蛋白質一律用生重當基準（食物代換表就是用生重，採買清單也需要生重）。
- 「熟重 150g」的主食，數值必須是熟的；TFDA 沒有熟樣品時用生數值＋失水率推算並記下公式。
- 水煮會讓水溶性維生素和鉀流失，App 沒有追蹤這些營養素，忽略。

## 4. 鈉

建議量：衛福部每天鈉不超過 2400 mg（約 6g 鹽）；WHO 不超過 2000 mg。

自煮時鈉主要來自調味料（TFDA 數值換算常見用量）：

| 調味料 | 常見用量 | 鈉 |
|---|---|---|
| 鹽 | 1g | 約 390 mg |
| 醬油（P0700101） | 1 大匙（約 17g） | 約 850 mg |
| 蠔油（P0800301） | 1 大匙（約 18g） | 約 1050 mg |
| 味噌（P1200101） | 1 大匙（約 18g） | 約 750 mg |
| 日式照燒醬（P1002901） | 20g | 約 370 mg |
| 韓式泡菜（R4400301） | 30g | 約 150 mg |

外食與超商才是鈉的大宗；台灣包裝食品依法必須標示鈉，超商品項的鈉比纖維還好收集，外食只能估算。

鈉與體重校正：校正引擎看 28 天趨勢，一兩天的水分波動影響不了它；但使用者看到「吃火鍋隔天重 1 公斤」容易產生全有全無的心態。只放一段固定說明文字（「一兩天內的體重起伏多半是水分，App 看的是 4 週趨勢」），**不把某一餐的鈉和某天的體重連在一起做提示**（那等於分析使用者行為後下評語）。

## 5. 拍板後的規格

> 2026-09-28 經第二輪獨立審核修正（[逐字紀錄](../../collab/opus-review-log/2026-09-28-lighten2-review-and-charter.md)）。**權威規格在 `docs/CHARTER.md` B5.6–B5.8、C4.5 與 `docs/PRD.md` 第 3 節**，本表只是摘要，兩者不一致時以章程為準。

| 項目 | 規格 |
|---|---|
| 用油 | 用油是隱含成分 `cooking_oil`（TFDA M1100101 大豆油，5g ≈ 44.2 kcal、脂肪 5g）。烹調法以 `implicit` 引用：煎 5g、炒 5g＋有蔬菜 5g、免開火與微波 0、氣炸與烤 0（實際 0–2g，取下限）。克數是 `assumption`（假設值） |
| 用油習慣 | 基本資料「家裡用油習慣：少／一般」，少＝減半。**推薦卡片、計畫、自己選的預設用油都依這個設定算** |
| 自己選的用油選項 | 煎或炒時可選：預設用油、約 1 茶匙（5g）、約 2 茶匙（10g）；結果記進這一餐的內容快照 |
| 縮放 | 用油與調味不跟主要槽位縮放；推薦熱量實際怎麼變，以 −1b 的 `diff-recs` 差異報告為準 |
| 鈉 | 食材取 TFDA「鈉(mg)」欄，超商取包裝標示，**外食沒有出處就是 null**。只中性顯示「鈉 約 X mg（參考 2400 mg）」；有品項沒資料時照加有資料的部分，並註明「部分品項無資料」；不上色、不警告、不做頻率統計、不參與推薦評分 |
| 自煮調味 | `seasoned: true` 的餐型加調味程度：清淡約 300 mg、一般約 700 mg（`assumption`，依據：一般＝鹽 1g 約 390 mg＋醬油 5g 約 250 mg ≈ 640，取 700）。**已選醬料（照燒醬、泡菜等）時預設清淡，否則預設一般**；自己選可切換 |
| 飽和脂肪 | 資料記 `sat_fat_g`，暫不顯示；缺資料的處理同鈉 |
| TFDA 空值 | 油的鈉、蔬菜的飽和脂肪這類 TFDA 為 null 但實際接近 0 的，標 `derived` 填 0 並附說明 |
| 體重說明 | 體重紀錄處放一段固定說明文字，不做個別事件提示 |
