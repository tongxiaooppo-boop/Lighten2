輕盈計畫　使用說明

照 App 現在實際的樣子寫。按鈕與提示文字用「」括起來，跟畫面上的字一樣。分頁和 App 一樣，可以一邊開 App 一邊對照。

先看這裡：App 怎麼用

這份說明的分頁

  • 基本資料（含最下面的 資料備份）
  • 今日建議：建議卡，以及「自己選」視窗的 開啟畫面、超商、外食、自煮、加飲品・單品、底部與送出、我的組合
  • 我的食物：搜尋、我的組合、子分頁 超商／外食／自煮／飲品・水果、你標了不吃的全部
  • 本週總覽、運動紀錄
  • 速查：看到這些字是什麼意思

上方有五個分頁：基本資料 今日建議 我的食物 本週總覽 運動紀錄。

第一次使用的順序：

  1. 到「基本資料」填年齡、身高、體重等，按「計算」。沒有這一步，「今日建議」「本週總覽」不會有東西，「我的食物」裡的「常吃」「不吃」也不能按。
  2. 回「今日建議」，每個時段（早餐、午餐…）會有一張建議卡。可以直接「記錄這餐」，或按「自己選」自己挑。
  3. 吃過的東西記下來之後，「今日建議」上方的數字會跟著變，「本週總覽」會累積。

先知道的幾件事

  • 每個畫面標題旁的「?」（基本資料、今日建議、我的食物、本週總覽、運動紀錄，以及「自己選」視窗右上角）會直接打開這份說明對應的那一段。基本資料最下面也有「打開使用說明」，可以從頭看。
  • 資料只存在這台手機（或電腦）的瀏覽器裡，沒有帳號、不會同步。換手機或清除瀏覽器資料前，請先到「基本資料」最下面「匯出備份」。
  • 基本資料的設定要按「計算」才會存。只改了欄位、沒按「計算」就離開，下次不算數。
  • 今天的餐在「今日建議」記。過去 7 天（不含今天）的一餐，可以到「本週總覽」補記；未來的日子可以先排預約。體重和運動則可以選日期。
  • 「常吃」是把你常吃的東西標起來，「自己選」和「我的食物」會把它們放在最上面一組，數量不限。只影響排列，今日建議的推薦不受影響。跟「不吃」互斥，同一樣東西不能同時是常吃和不吃。
  • 畫面上「約 N kcal」的數字，是用食物資料算出來的參考值，不是精確值。鈉、飽和脂肪等只是中性顯示，沒有顏色、也不會警告你。
  • 這份說明裡圖片或例子的數字，是測試資料，不要當成你的標準。

基本資料

這一頁是做什麼的：告訴 App 你的身體數據、飲食限制和作息，它才算得出每天的熱量與營養目標，並決定建議與「自己選」裡哪些東西可以出現。

畫面上有哪些區塊（由上往下）

生理數據
年齡、性別、身高 (cm)、體重 (kg)、體脂率 (%)（選填）。年齡、身高、體重一定要填。
活動量
「日常活動等級」：久坐／輕度活動／中度活動／高度活動。指的是平常的日子，不是這週運動了幾次（運動紀錄分頁跟飲食熱量是分開的）。
飲食限制與過敏原
  • 「飲食型態」：一般／蛋奶素／全素／無特殊限制。
  • 「家裡用油習慣」：一般／少油（用油減半）。自煮的煎、炒會把用油算進熱量：煎約 5g、炒約 5g（有蔬菜再加 5g），選「少油」就減半。
  • 「低碳」勾選：只影響今日建議（一餐碳水 30g 以內），「自己選」不受影響。
  • 過敏原／不耐（勾選要避開的）：甲殼類、軟體動物、魚、蛋、乳製品、花生、堅果、麩質、黃豆、芝麻、芒果。只要勾了任何一項，成分還沒逐項確認過的品項（多數便當、外食餐盒）也會一起避開，在「自己選」和「我的食物」裡會灰掉，寫「成分未確認」。
今日建議時段與來源
早餐、午餐、下午茶、晚餐、宵夜各一個下拉選單：「不顯示建議」「無偏好」「超商」「外食/外賣」「快煮（≤15分鐘）」「正常煮」。
  • 選「不顯示建議」＝這個時段不需要建議，今日建議的那張卡會寫「已設定不需要這個時段的建議，可到基本資料分頁調整」。
  • 其他選項是這個時段偏好的來源：建議會往這個方向挑，「自己選」打開時也會先停在對應的分頁（見下面〈打開時停在哪一頁〉）。
  • 預設：早餐、午餐＝超商，晚餐＝正常煮，下午茶和宵夜＝不顯示建議。
目標
目標模式：減脂／維持／增肌。

常見操作

第一次填資料並算出目標：

  1. 填年齡、性別、身高、體重，選活動量、飲食型態、目標模式，勾你的過敏原，調好各時段。
  2. 按最下面的「計算」。有漏填會跳出「請填寫年齡、身高、體重後再計算。」
  3. 表單下方出現「計算結果」：基礎代謝 BMR、每日消耗 TDEE（起點值）、目標熱量、蛋白質、脂肪、碳水化合物、膳食纖維、淨碳水。 如果算出來的熱量低於安全下限，會看到「已套用熱量安全下限（女性 1200 kcal／男性 1500 kcal）…」的說明，並以下限為準。

改任何設定（飲食型態、過敏原、各時段來源…）：改完一定要再按一次「計算」。重新整理頁面後設定還在。

記體重：在「今日體重回填」選日期（預設今天）、填體重，按「送出」，下面會寫「已記錄 日期 體重 kg」。

「體重趨勢校正」卡片

算出目標後會出現這張卡，它根據你近幾週的體重變化，微調每日目標：

  • 「公式目標」：只用身體數據算的熱量；「校正值」：目前加減了多少；「目前每日目標」：實際在用的數字。
  • 體重紀錄不夠時寫「需要近4週至少8次體重紀錄」；夠了會寫「近4週體重趨勢：±N kg／週」和目前狀態（例如「目前無需調整」「已調整，下次可調整日期：…」「已達累計調整上限（±300 kcal）」）。
  • 調整一律「明天起」生效，不會改到今天。卡片上會寫「明天起：N kcal」。
  • 有時它會問你要不要調整（例如體重上升）：按「套用」就調整，按「先不要」14 天內不再提醒。想回到公式目標就按「重設校正」。
  • 今日建議上方如果出現「基本資料有一項目標調整建議待你確認」，點它會跳到這裡。

「資料備份」也在這一頁最下面，見〈資料備份〉。

資料備份（在基本資料分頁最下面）

資料只存在這台裝置的瀏覽器裡。換手機、清除瀏覽器資料、或想保險一點之前，先匯出備份。備份包含：基本資料、飲食紀錄、體重紀錄、運動紀錄、我的品項、我的組合，以及不吃清單、常吃清單、設定等。

匯出

  1. 按「匯出備份」。
  2. 會下載一個檔案，名稱像 lighten2-backup-今天日期.json（iPhone 會跳出分享／存到「檔案」；Android 在「下載」）。
  3. 下方寫「已下載 …（飲食紀錄 N 筆、體重紀錄 N 筆、我的品項 N 筆、我的組合 N 筆）。」

建議用 Safari 或 Chrome 開；LINE 等 App 內建的瀏覽器常常下載失敗。如果看到「這份備份目前無法還原：…」，資料沒有損失，但這份檔案不要依賴，請告訴開發者。

還原

  1. 按「從備份還原」，選剛才的檔案。
  2. 出現預覽表格：基本資料／飲食紀錄／體重紀錄／運動紀錄／我的品項／我的組合，每列左邊是備份檔裡的筆數與最後日期，右邊是這台目前的。只顯示筆數與日期，不顯示內容。
  3. 下面的說明要看：「目前有 M/D 匯出這份備份之後新增的紀錄，還原後不會保留。」「還原會取代這台裝置上的所有資料，不是同步。」
  4. 如果目前這台已經有資料，「還原」是淡色的。要先按「先匯出目前的資料」（會再下載一個檔案），或勾「目前的資料不需要保留」，才能按。
  5. 按「還原」：頁面重新載入，資料就是備份當時的樣子，備份之後記的都不見。按「取消」就關掉預覽、資料不變。

選到不是備份的檔案（照片、文字檔）會顯示「這個檔案不能還原：…」，沒有「還原」按鈕。

今日建議

上面這排：「建議卡」是今日建議頁本身；其餘對照「自己選」視窗：超商｜外食｜自煮是視窗最上面的三個分頁；「加飲品・單品」是三個分頁共用的兩個步驟；「底部與送出」是視窗最下面固定的摘要與按鈕；「我的組合」是最上面那一列與最下面的「存成組合」。

這一頁是做什麼的：看今天還剩多少熱量與營養可以吃，每個時段給一張建議卡；吃了就記下來。這是每天最常用的一頁。

還沒填基本資料時會寫「請先到「基本資料」分頁填寫並按「計算」後，再回來看今日建議。」

最上面的日期列

頁面最上面有一排七個日子：「今天」加未來 6 天（例如「週六 10/03」）。預設停在今天。有預約的日子，底下有一個小點。

點未來的日子，看到的跟今天不一樣：

  • 沒有推薦，也沒有彙總卡。
  • 最上面一行「已排 N 餐，約 X kcal」。
  • 每一餐寫「還沒排」，下面有「自己選」；開著的時段還有「這餐不吃」。

點回「今天」就回到下面說的建議卡。

畫面上有哪些區塊

最上面的彙總卡

  • 大數字與「接下來幾餐的建議熱量」：今天的目標扣掉已記錄的，剩下可以分給後面幾餐的熱量。所有開啟的時段都記完以後，改寫「今天的餐點都記錄完了」，不再顯示數字（避免像是在叫你再吃一餐）。
  • 「建議合計 N kcal」：目前各張建議卡加起來的熱量；跟大數字差 20 kcal 以上時，會在後面括號標差多少。
  • 「蛋白質」「纖維」：今天已記錄的／目標，例如「35 / 90g」。
  • 「近7天平均」：不含今天，寫「近7天平均 N／目標 N kcal」；資料不夠時寫「資料不足」。
  • 「營養素明細」（點開）：蛋白質、脂肪、碳水（參考值，是目標熱量扣掉蛋白質與脂肪後反推的，不是獨立的建議值）、纖維，另有「鈉 約 N mg（參考 2400 mg）　飽和脂肪 約 N g」。沒資料寫「無資料」，部分品項沒資料寫「（部分品項無資料）」。 如果寫「今天有 N kcal 來自沒有脂肪/碳水資料的品項…」，表示那幾樣只知道熱量，脂肪、碳水沒算進上面的數字。
  • 有時會多一行校正提示，見上一段〈體重趨勢校正〉。

「重新整理建議」按鈕

重新算一次今天的建議。切到別的分頁再切回來時，建議卡不會整批換掉；想換才按這個。

五張時段卡（早餐、午餐、下午茶、晚餐、宵夜）

一張卡可能是下面幾種樣子：

有建議
每個時段一張固定的時段插畫（不是食物照片）、建議的名稱，下面一行像這樣：● · 約 700 kcal（基準 640 kcal，含用油約 10g，未含沙拉醬）· 配額 700 kcal
  • 小圓點是準備難度：綠、黃是「快煮」做得到的簡單程度，紅比較費工、要「開伙」。
  • 「約 N kcal」是配合你這個時段配額放大或縮小之後的熱量；「基準」是原本食譜的熱量；「配額」是這個時段分到的熱量。
  • 「含用油約 Ng」是自煮把煎炒的油算進去；「未含沙拉醬」之類寫「未含…」，表示那樣東西沒有算進熱量（見〈自煮〉）。
卡片上的按鈕：
  • 「順便不要：」後面的小標籤（例如某個食材或品項名稱）：按了就把它標成不吃，之後推薦與「自己選」都不再出現它。上方會寫「已標不吃「…」，可以在「我的食物」取消。」如果那一樣原本標了常吃，也會一併取消常吃（同一樣東西不能同時是常吃和不吃）。
  • 「倒讚」：這個時段換一個建議。
  • 「記錄這餐」：照建議的內容記下來。
  • 「自己選」：自己挑要吃什麼，見〈「自己選」詳細說明〉。
已記錄
卡片變成「已記錄：名稱（約 N kcal）」，旁邊有「撤銷」（這一餐刪掉、回到建議）和「存成組合」（見〈我的組合〉；有用「直接估算」的那一餐沒有這個按鈕）。一個時段記了兩筆以上時，按鈕會帶上名稱。
「預約 · 約 N kcal」
這一餐在前幾天排過預約。按「記下」才算吃過，也可以「改」或「取消預約」。見下面〈到了那一天〉。
「這餐沒吃」
你按過「這餐不吃」，這一餐記成 0 大卡。旁邊有「撤銷」。見下面〈這餐不吃〉。
「這個時段的配額已經不多了」
前面的時段吃得多，這個時段分到的熱量很少，所以不給建議。下面仍有「自己選」，照樣可以記，不會被擋。
「暫無適合的組合」
在你的設定下找不到合適的建議（例如限制很多）。同樣有「自己選」。
「今天這個來源沒有合適的選擇，已改為一般推薦」
你設定這個時段偏好某個來源（例如超商），但今天找不到，就改用一般的挑法。
「已設定不需要這個時段的建議，可到基本資料分頁調整」
這個時段在基本資料設成「不顯示建議」。

排預約（未來的日子）

想先排好明天或之後的某一餐（例如週六晚上聚餐）：

  1. 在日期列點那一天。
  2. 在那一餐按「自己選」，標題會寫「排進 10/03（週六）：晚餐」，記錄的按鈕改成「排進預約」。
  3. 選法跟平常一樣，見〈「自己選」詳細說明〉。聚餐可以用「外食」分頁的「找不到？直接估算」。
  4. 按「排進預約」。

視窗裡會寫「預約不計算配額」，意思是排預約不會動到那一天的配額。排好的卡片可以按「改」或「取消預約」。

也可以預約「這餐不吃」，例如明天早上要空腹抽血。

到了那一天

  • 預約的卡片寫「預約 · 約 N kcal」。App 不會自動當作你吃了，要按「記下」才算吃過。也可以「改」或「取消預約」。
  • 其他餐的建議會先扣掉預約的熱量。
  • 彙總卡的大數字不扣預約，下面多一行「已排：晚餐 約 1200 kcal」。
  • 如果其他餐的配額因為預約變得很少，卡片會寫「晚餐已經排進來了，這餐照平常吃就好」。意思是照平常吃就好，不用為了聚餐少吃。
  • 預約的東西之後被你標了不吃，或被刪掉，卡片會寫原因，那一餐改回建議。

這餐不吃

今天每一餐的卡片下面有「這餐不吃」。按了會記成 0 大卡，卡片寫「這餐沒吃」，旁邊有「撤銷」。其他餐的配額會變多。

  • 在「基本資料」關掉的時段（下午茶、宵夜預設是關的）沒有這個按鈕。
  • 為什麼要記：一天每個開著的時段都有紀錄，才算「完整的一天」，體重趨勢校正比較準。
  • 不確定有沒有吃，就不要按。

昨天的餐

隔天打開「今日建議」，如果昨天有開著的時段沒有紀錄，最上面會出現一張收起來的卡片「昨天的餐（N 餐）」。按標題展開，每一餐一列。

  • 昨天排過預約的那一餐：「吃了」照預約記下，或按「改」換內容。預約的是「這餐不吃」，按「沒吃（照預約）」。
  • 昨天看過建議的那一餐：寫「昨天看到的建議：名稱」，按「吃了」照建議記下。
  • 每一餐都有「S」「M」「L」（小、中、大約略的熱量，列上有寫約幾 kcal），按一下記成約略的一餐；也有「這餐沒吃」（記成 0 大卡）。
  • 「不確定」：這一列先收起來，不寫任何紀錄。重新開啟 App 後會再出現。
  • 「先不用」：整張卡收起來。

想補更前面的日子，或想完整選品項，見〈本週總覽〉的「補記過去的一餐」。

常見操作

照建議吃：按「記錄這餐」→ 卡片變成已記錄、上方數字更新。記錯了按「撤銷」。

不喜歡這個建議：按「倒讚」換一個；只是不想要其中某個食材，按「順便不要」下的那個標籤。

自己決定吃什麼：按「自己選」（下面整章在講）。

想把剛記的這一餐存起來以後一鍵再用：已記錄的卡片上按「存成組合」→ 名稱欄（預填品名，可以改）→「存」，寫「已存成組合「…」，在「自己選」最上面。」

「自己選」詳細說明

在「今日建議」任何一個時段卡上按「自己選」，會跳出一個視窗「自己選這一餐：午餐」（時段名稱依你按的那張卡）。你可以從超商、外食、自煮三種來源挑，再補上飲品、水果或單品，最後按「記下這餐」。

整個視窗的結構

  • 最上面：標題與三個分頁「超商」「外食」「自煮」。
  • 中間（可以上下捲）：選東西的地方。依序是：（如果存過組合）「我的組合」一列 → 目前分頁的內容 → 共用的「加飲品・水果」→ 共用的「加點單品」→（記下之前）「存成組合」的勾選。
  • 最下面固定不動：提示一行、摘要、缺口說明，以及「取消」「記下這餐」兩個按鈕。手機一打開就看得到，不用往下捲。

步驟編號是連續的：超商與外食是「1. 選品項」「2. 加飲品・水果（選填）」「3. 加點單品（選填）」；自煮的編號在後面〈自煮分頁〉說明。

打開時看到什麼、停在哪一頁

打開時停在哪個分頁，依序看：

  1. 這個時段在「基本資料」設的來源：設「超商」就停在超商、「外食/外賣」停在外食、「快煮」或「正常煮」停在自煮（子切換也對應停在「快煮」或「開伙」）。
  2. 如果那個時段設的是「無偏好」或「不顯示建議」：停在這個時段上次記下的那一頁（只有按「記下這餐」成功才會記住；切過分頁沒送出不算）。
  3. 都沒有：停在「超商」。

預設值是早餐、午餐停在超商，晚餐停在自煮的「開伙」。想換預設，到基本資料改該時段的來源再按「計算」。

超商分頁的做法，外食分頁也一樣（品項怎麼分組、灰色原因、份量晶片、數量上限、新增品項都相同）。外食多了「自助餐」和「找不到？直接估算」，在「外食」子分頁。

超商與外食分頁

品項怎麼分組

  • 「1. 選品項」底下第一組是「常吃」（你標了常吃的才會出現，見下面〈標「常吃」〉）。常吃的東西是搬過去，原本的分類裡不再出現，每樣只出現一次。
  • 接著分區：主餐 → 配菜 → 點心。
  • 每一區裡再依分類分小組（超商例如「健身餐盒」「沙拉」；外食例如「便當」「麵食」，外食還有連鎖健康餐盒）。小組的順序照資料原本的順序，不是照熱量排。
  • 卡片只有名稱和「約 N kcal」，沒有圖片。
  • 外食分頁裡台式外食在前、連鎖餐盒在後。
  • 列出哪些品項會看時段：同一家的東西，早餐、午餐、下午茶看到的不一樣（下午茶、宵夜列出的比較少）。飲料不看時段，任何時段都能選。
  • 你自己新增的「我的品項」收成一組「我的品項（N）」放在最後，平常收著，有已選的就自動展開。

點卡片＝選取，再點一次＝取消

可以多選，但每個角色有上限，見〈每個角色最多選幾個〉。選了之後，這個品項會出現在清單最上面的「已選（可以改份量）」段。

灰色的項目與原因

被你的設定擋住的品項會灰掉、不能點，卡片上寫原因：

「含過敏原」
品項含有你在基本資料勾的過敏原。
「成分未確認」
你勾了任何過敏原，而這個品項的成分沒逐項確認過，所以保守地避開（多數便當、外食餐盒會這樣）。
「飲食限制未確認」
你的飲食型態是蛋奶素或全素，而這個品項沒有宣告符合。
「你標了不吃」
你自己標了不吃的品項（見下一段）。
  • 清單最上面會有一行「灰色的 N 項因你的過敏原／飲食設定不能選。」
  • 同一個小組裡，能選的排前面、灰的排後面。
  • 如果整個小組都不能選，會收成一行，例如「沙拉（4 項因設定不能選）」，點開才看到灰掉的卡片。
  • 沒勾過敏原、也沒設素食時，不會有灰色項目（「你標了不吃」除外）。
  • 如果整個分頁都沒東西能選，會寫「這個時段的超商分頁沒有可以選的品項，可以看看其他分頁，或只記飲料。」

分類預設收起來

  • 超商、外食分頁的每個分類（例如「健身餐盒」「沙拉」）預設收著，標題後面寫筆數，點一下打開。
  • 「常吃」那一組和「已選」照樣打開。
  • 關掉「自己選」再打開，回到預設的收合狀態。

「常吃」那一組

被過敏原或飲食限制擋住的常吃品項留在「常吃」組，灰在組的最後；選了的常吃品項還是選著，只是排在常吃組裡。常吃只影響「自己選」的排列。

「你標了不吃」那一組

標了不吃的內建品項不會留在原位，而是移到分頁最下面收起來的「你標了不吃（N）」。裡面的卡片灰掉不能點，旁邊有「取消不吃」，按了就回原位、可以選。

標「常吃」

把自己常吃的東西標起來，「自己選」會把它們放在最上面一組「常吃」，不用每次翻分類。數量不限。常吃只影響自己選的排列，今日建議的推薦不受影響。標法見下一段；也可以到「我的食物」標（見〈我的食物〉）。

  • 同一樣東西不能同時是常吃和不吃：標常吃會自動取消不吃，標不吃會自動取消常吃。
  • 還沒填基本資料（沒按「計算」）時，「常吃」跟「不吃」一樣是淡色不能按，說明寫「先在基本資料填好身體數據並按計算，才能標「常吃」「不吃」。」

份量晶片、已選段的「常吃」「不吃」「複製成我的版本」

選了超商或外食的品項後，清單上方「已選（可以改份量）」每個品項一行：

  • 份量晶片：「半份」「1 份」「×1.5」「×2」。選中的那一個有顏色，預設是「1 份」。按了之後，下面摘要的熱量與營養馬上跟著變（晶片上不會顯示熱量）。紀錄名稱會寫成「名稱 ×2」或「名稱（半份）」。取消這個品項時，份量也跟著清掉。
  • 「常吃」（標了變「取消常吃」）：把它標成常吃，它還是選著，只是搬到最上面的「常吃」組。內建品項這一行的按鈕是「常吃、複製成我的版本、不吃」；你自己新增的品項只有「常吃」。選中的現成飲料那一行也一樣。在選擇器裡標常吃不會跳提示列。
  • 「不吃」（只有內建品項有；你自己新增的沒有）：把它標成不吃。如果它原本是常吃，常吃會自動取消。這個品項從已選拿掉、移到最下面的「你標了不吃」，上方出現「已標不吃「…」，可以在「我的食物」取消。」和「復原」。
    • 按「復原」就回到原本的位置、可以再選。
    • 這是真的寫進你的不吃清單，推薦也會避開它。如果你直接按「取消」關掉視窗，今日建議會馬上換掉它，不用再切分頁。
    • 之後想取消，到「我的食物」處理。
  • 「複製成我的版本」（只有內建品項有）：因為內建的熱量或內容跟你實際吃的不一樣時用。會跳出表單，名稱、熱量、角色、適合的時段等都預先帶好內建的值，你改成自己的數字，按「存成我的品項」。
    • 原本那個內建品項會換成你的版本（在「我的食物」該分頁的「已換成我的版本」可以「改回內建」）。如果原本的內建品項是常吃，常吃會換成你的版本。
    • 新的「我的版本」自動選進這一餐，份量沿用你剛選的（例如 ×2），並說明「已複製成我的版本「…」，並選進這一餐。」

現成飲料選中後，它的份量晶片出現在「加飲品・水果」步驟裡、那一杯的下面，用法一樣。（單品不用晶片，用步進器，見〈加點單品〉。）

每個角色最多選幾個

為了避免記出不合理的一餐，每個角色（品項右上的分類：主餐、配菜、點心、飲料）有數量上限，只算目前這個分頁選的東西和那一杯現成飲料：

角色最多
主餐早餐、午餐、晚餐各 2 個（例如雞胸＋蒸地瓜）；下午茶、宵夜 1 個
配菜1 個
點心1 個
飲料（現成飲料）1 杯
  • 已經選滿了還想再選，會跳出提示，例如「午餐的主餐最多選 2 個。」，那一項不會被選進去。
  • 「直接估算」和「加點單品」不佔這些名額（單品另有一餐最多 4 項的上限）。
  • 不要求一定要有主餐：只選一杯拿鐵、只選一個點心也能記成一餐。至少要選一樣東西，否則「記下這餐」按不下去，上面寫「請至少選一個品項。」

「＋新增到我的品項」快速新增與「補填」

清單裡沒有你吃的東西，又想記得準一點：在超商或外食分頁最下面按「＋新增到我的超商品項」（外食分頁則是「…外食品項」）。新增在哪一個分頁，就屬於那個分頁的來源。

快速新增表單

  • 「名稱（必填）」「熱量 kcal（必填）」。
  • 「角色」：主餐／配菜／點心／飲料。早餐、午餐、晚餐預設「主餐」，下午茶、宵夜預設「點心」。選「飲料」的話，新品會放進「加飲品・水果」的現成飲料，並取代你目前選的那一杯。
  • 「過敏原」：「未確認」（預設）／「確認不含」／「含：」（再勾是哪些）。
  • 「更多（選填）」：蛋白質、碳水、脂肪、纖維、飽和脂肪、鈉。有填的才會算進摘要，沒填就是「無資料」。 「這個品項是：全素／蛋奶素／都不是」：如果你的飲食型態是全素或蛋奶素，這一行直接放在表單上；沒設的話收在「更多」裡。
  • 按「存成我的品項」存檔；按「取消」收起來。沒填名稱或熱量會提示「請填名稱」「請填熱量（大於 0 的數字）」。

存完之後會怎樣

  • 能選的話：「我的品項」那組自動展開、新的一筆已選中，並寫「已存成我的品項，並選進這一餐。」
  • 被你的設定擋住：照樣存起來，但不選中，寫「已存成我的品項。以你目前的設定不能選：…」。
  • 該角色已經選滿：存起來但不選，寫「…這次沒有幫你選。」
  • 如果你勾了過敏原、又照預設「未確認」，存之前表單下方就會預告：「以你目前的設定，這樣存會不能選：你設了過敏原「蛋」，過敏原未確認的品項不能選。」只是說明是哪個設定造成的，不會叫你改填。

「補填」

你新增的品項如果過敏原是「未確認」，而你之後勾了過敏原，它會灰掉、寫「成分未確認」，旁邊多一個「補填」按鈕：

  1. 按「補填」，跳出同一個表單（標題「補填我的品項」）。
  2. 把過敏原改成「確認不含」（或「含：」並勾選），按「存檔」。
  3. 能選了就直接選中，還是只有一張卡片。

寫了「含過敏原」的品項沒有「補填」——它本來就含你要避開的東西。只有「成分未確認」「飲食限制未確認」這類可以補。

外食分頁跟超商分頁的操作一樣：品項分組、灰色原因、「你標了不吃」、份量晶片與「不吃」「複製成我的版本」、每個角色的數量上限、「＋新增到我的外食品項」與「補填」都請看「超商」子分頁。差別是：清單內容換成台式外食（便當、麵食…，在前）和連鎖健康餐盒（在後），並且最上方多了「自助餐」和「找不到？直接估算」兩張卡。

外食的「自助餐」與「找不到？直接估算」

「外食」分頁最上面有兩張卡：「自助餐」和「找不到？直接估算」。下面先說「自助餐」。

「自助餐」

用在自助餐、吃到飽、朋友家這類沒有品項可選的一餐。記的是你自己吃的那一份。按標題「自助餐」展開，依序選：

  1. 名稱欄可以填（選填，例如「吃到飽」）。
  2. 主食：白飯、糙米飯、雜糧飯、白麵、不吃。
  3. 主食量：小、中、大，分別是 2、4、6 份。飯是 80、160、240g，麵是 120、240、360g。選了「不吃」就沒有這一步。
  4. 幾道菜：1 到 4 道。
  5. 每一道菜的類別：素菜、菜肉、純肉。純肉是肉、魚、蛋、豆腐為主。
  6. 菜量：小、中、大，分別是 120、160、200g。這是所有的菜加起來的量，再分給每一道，所以選 4 道不會比選 1 道多。
  7. 湯：要不要加一碗（250ml）。
  • 下面的預覽寫「約 N kcal · 蛋白質 N g · 鈉 N mg」，後面括號是主食、菜、湯各幾克。
  • 預設的主食量和菜量會依你的目標先選好：菜量看蛋白質目標，主食量看這個時段的熱量配額。都可以自己改，記下的數字就是畫面上選的。
  • 數字是依常見家常菜的平均估算，是「估計」，不是這一餐的實際數字。
  • 按「加入這一餐：…」加進來，再按「記下這餐」。排預約、補記過去的一餐也都能用。
  • 跟「找不到？直接估算」一樣：不會檢查過敏原或飲食設定，也不能存成組合。

「找不到？直接估算」

用在聚餐、喜宴、或清單裡找不到的外食，只選大小（S／M／L）：

  1. 名稱欄可以填（選填，例如「喜宴」）。
  2. 按大小：「S 小份」約 400 kcal、「M 一般」約 700 kcal、「L 大餐」約 1200 kcal。
  3. 下面出現一個已加入的標籤，例如「喜宴（L，約 1200 kcal）×」。可以加好幾筆；點那個標籤（尾巴的「×」）就拿掉。
  • 估算只存在這一餐，不會變成品項。沒填名稱，紀錄就寫「外食估算」。
  • 估算沒有蛋白質、纖維等資料，所以摘要的這幾格是「—」，缺口說明會寫「蛋白質：無資料」「纖維：無資料」。這是「不知道」，不是 0。
  • 估算不會檢查你的過敏原或飲食設定（它是你自己宣告吃了什麼）。
  • 熱量超過這個時段配額時，會寫「這餐約 N kcal，這個時段配額約 N kcal（+N），先記下來，其他餐會自動調整。」記了之後，後面時段的建議熱量會跟著重新分配。
  • 有估算的這一餐不能存成組合。

自煮分頁

用食材自己組一餐：先選難度、選「餐型」，再依序選食材、烹調法、用油、份量。選項會即時灰掉不合適的，並寫原因。

步驟 1：快煮或開伙

  • 「快煮（簡單料理）」：食材和烹調法都要是簡單的（準備難度圓點綠、黃）。
  • 「開伙」：不限難度，快煮做得到的它都包含。
  • 這個選擇會成為這一餐的紀錄型態（快煮／開伙）。
  • 在快煮裡，比較費工的食材和烹調法（例如「烤／氣炸」、鮭魚、去皮雞腿肉）會灰掉，寫「快煮不含這個食材」或「快煮不含這個烹調法」。 如果你先在開伙選好、才切到快煮，已選的東西還在，仍然可以點掉；但「記下這餐」會按不下去，提示「快煮不含「烤／氣炸」，請換成開伙或換掉它。」換掉或切回開伙就好。

煎蛋類早餐、午餐、晚餐、宵夜
炒類午餐、晚餐
烤／舒肥定食午餐、晚餐
溫沙拉午餐、晚餐

滷燉定食午餐、晚餐
低碳蛋白質蔬菜盤午餐、晚餐
  • 點一次選取。再點一次已選的餐型＝取消餐型。換成別的餐型，之前選的食材會全部清掉重來。
  • 可以不選餐型：如果只想記單品（例如只吃一碗白飯），或只記一杯飲料，不用選餐型，直接到下面「加點單品」「加飲品・水果」就能記。
  • 選了餐型但還沒配完，又加了單品：提示會多一句「（只記單品可以再點一次「煎蛋類」取消餐型）」。照做就能只記單品。

「共餐」：記家裡一起吃的那一餐

「選餐型」那一排最後多一個「共餐」。家裡煮了幾道菜一起吃，記你自己吃的那一份。

  • 只有「開伙」、午餐和晚餐才有。早餐、下午茶、宵夜和「快煮」沒有。
  • 跟餐型擇一：按「共餐」會清掉已選的餐型；再選餐型，共餐就收起來。切到「快煮」也會收起來。

按「共餐」後，出現「選家常菜」這一步，依序是：

  1. 主食與主食量（小、中、大，跟「自助餐」一樣）。主食可以選「不吃」。
  2. 家常菜，選 1 到 4 樣。分「素菜」「菜肉」「純肉」三組，一年共 32 道，只列當季的（每個季節每一組至少 3 道）。
  3. 菜量：小、中、大（120、160、200g）。這是所有的菜加起來的量，平分給每一道。
  4. 湯（選填）：至多 1 道，或「不加」。
  • 預設的主食量與菜量依你的目標先選好：菜量看蛋白質目標，主食量看這個時段的熱量配額。都可以自己改。
  • 已選但後來不是當季的菜，卡片標「非當季」，點一下可以取消。
  • 下面一行小字寫每道菜約幾克。數字是依家常菜配方估計的，不是這一餐的實際數字。
  • 記錄名稱寫成「共餐：菜名＋…」。
  • 可以記下、預約、補記，也可以存成組合。
  • 有設過敏原或素食時，家常菜全部不能選（家常菜的成分沒有逐項確認）。這時可以改用外食分頁的「自助餐」估算。

步驟 3：選食材與烹調法

選了餐型後出現「3. 選食材與烹調法」，分成幾個軸（這個餐型沒有的軸就不出現）：

軸規則
蛋白質必選，最多 2 個
主食必選，選 1 個（煎蛋類沒有主食這一軸）
蔬菜選填，最多 3 個（早餐碗沒有蔬菜這一軸）
醬料選填，選 1 個，另有「不加」（只有部分餐型有）
烹調法必選，選 1 個
  • 選滿上限（蛋白質 2、蔬菜 3）之後，其他選項灰掉寫「最多選 2 個」「最多選 3 個」；點已選的可以取消，騰出名額。
  • 餐型和烹調法的搭配是固定的：早餐碗只有「免開火／免烹調」「微波」；煎蛋類是「煎」「炒」；炒類只有「炒」；烤／舒肥定食是「烤／氣炸」「煎」「微波」；溫沙拉是「煎」「烤／氣炸」；蒸魚定食只有「蒸」；滷燉定食只有「滷／燉」；低碳蛋白質蔬菜盤是「煎」「炒」「烤／氣炸」。蒸和滷／燉不放油，所以沒有用油那一步。
  • 低碳蛋白質蔬菜盤沒有主食這一軸。「滷燉定食」的摘要會寫「未含滷汁拌飯」，表示滷汁的熱量與鈉沒有算進去，實際拌飯吃了會比摘要高。
  • 常吃：自煮的選項不搬組，每一欄（蛋白質、主食、蔬菜…）裡，你標了常吃而且沒被擋的排在第一個；被擋的常吃留在原本位置灰著。
  • 食材一樣會被你的過敏原、飲食型態擋掉（灰掉，寫「含過敏原」「成分未確認」「飲食限制未確認」），你標了不吃的寫「你已設定不吃：雞胸肉」這樣。
  • 免開火的限制：選了烹調法「免開火／免烹調」，所有食材（蛋白質、主食、蔬菜、醬料）都不能是需要加熱的。需要加熱的食材會灰掉寫「這個食材需要加熱」；反過來，已經選了需要加熱的食材，「免開火／免烹調」會灰掉寫「已選的食材需要加熱」。硬湊的話提示是「免開火不能搭配需要加熱的食材，請換烹調法或換食材。」目前只有早餐碗有免開火。

步驟 4：用油與調味

只有需要的時候才出現這一步：烹調法有用油（煎、炒），或這個餐型有調味（除了早餐碗以外都有）。

  • 用油（只有「煎」「炒」會出現）：選項是「預設（Ng，依用油習慣）」「約 1 茶匙（5g）」「約 2 茶匙（10g）」，跟預設一樣的克數只會列一次。沒有「不用油」——煎炒一定會有油。預設的 N 是：煎 5g、炒 5g（有蔬菜再加 5g），基本資料的「家裡用油習慣」選「少油」就減半。這就是基本資料說的「家裡用油習慣」。選「烤／氣炸」「微波」「免開火」沒有用油這一列。
  • 調味：「清淡」「一般」。預設是「一般」；如果你這一餐選了醬料，預設就改成「清淡」（醬料本身有味道）。調味只增加鈉，不加熱量。
  • 用油量改了之後，摘要會寫「（含用油約 10g）」，熱量也跟著變。

步驟 5：份量（滑桿）

  • 標題寫「5. 份量（食材名）」，括號裡是被調整的那一個食材（主要槽位）：有主食的餐型是你選的主食（例如南瓜、白飯）；煎蛋類沒有主食，是你選的那個蛋白質（例如雞蛋）。
  • 滑桿 0.5 倍到 2.0 倍，每格 0.1，旁邊顯示「1.0 倍」這樣的字。拖動時摘要的熱量與營養立刻跟著變。
  • 只有那一個食材會被放大縮小，其他食材維持固定的一份標準量。
  • 主食還沒選、或煎蛋類選了 2 個蛋白質時，沒有主要槽位，就不會出現滑桿（都是 1 倍）。
  • 步驟編號是連續的：配出完整餐型時依序是 3、4、5，然後接「加飲品・水果」「加點單品」（沒有用油與調味那一步時，編號會自動往前補）。

「已配好／還沒配好」與「未含沙拉醬」

  • 摘要開頭寫「已配好」＝這個餐型該選的都選了，可以記；「還沒配好」＝還缺東西，旁邊的提示會告訴你缺什麼：「請選蛋白質」「請選主食」「請選烹調法」。什麼都沒選時只寫「還沒配好」，提示「請先選餐型」（但如果你有選單品或一杯飲料，就不需要餐型，可以直接記）。
  • 「未含沙拉醬」（溫沙拉才有）表示沙拉醬的熱量、鈉沒有算進去，因為不知道你淋多少。實際吃了醬的話，熱量會比摘要高。換成別的餐型就沒有這句。

這兩個步驟在超商、外食、自煮三個分頁都有，內容相同、選的東西三頁共用。

共用步驟：加飲品・水果

三個分頁都有這一步（超商、外食是步驟 2；自煮排在自煮步驟後面）。可以選一杯現成飲料，也可以加家裡的飲品（自己倒的牛奶、豆漿…）和水果。內容由上到下：

  1. 已選框：這一步裡你加的家裡飲品、水果會列在最上面，每一筆有名稱、步進器和「移除」。
  2. 常吃（你標了常吃的才會出現）：在已選框之後、「現成飲料」之前，現成飲料、家裡的飲品、水果標了常吃的都搬到這一組，每樣只出現一次。已選框裡每一列在「移除」旁邊有「常吃／取消常吃」。「不加」仍在現成飲料那一組。
  3. 現成飲料：分「超商」「手搖飲・咖啡・早餐店」「我的品項」三組。在超商分頁，超商那組排在最上面；在外食、自煮分頁，手搖飲那組排在最上面。預設只打開目前分頁對應的那一組，其他組點一下打開。第一張是「不加」（預設選中），其他是超商、手搖飲、豆漿、咖啡等「一杯」的東西，卡片有「約 N kcal」。一次只能選一杯，點別杯會換掉，點「不加」＝取消。選中後，那一杯下面出現份量晶片（半份／1 份／×1.5／×2）。灰掉的（被過敏原等擋住）排在最後。
  4. 家裡的飲品：例如「全脂奶（自己倒）」，按量算，用步進器。
  5. 水果（N）：預設收著。點開先看到大類（柑橘類、蘋果類…），再點開才看到每種水果。用步進器。
  6. 你標了不吃（N）：這一步最下面收著的一組，現成飲料、家裡的飲品、水果標了不吃的都放在這裡，各有「取消不吃」。

家裡的飲品和水果用步進器（跟「加點單品」一模一樣，下一段詳細說明）：

  • 點卡片＝加進來，一開始 1 份；卡片上標「已選 · 1 份」。
  • 「−」「＋」每按一下增減 0.5 份，範圍 0.5 份到 12 份；到 0.5 份時「−」按不下去，到 12 份時「＋」按不下去。
  • 「移除」直接拿掉，沒有確認視窗。

份量說明（步進器下面那行小字）怎麼讀，見下一段〈加點單品〉。

現成飲料不是單品：它不用步進器，用份量晶片，而且算在「飲料最多 1 杯」的名額裡。家裡的飲品和水果是單品，算在「單品最多 4 項」的名額裡。

共用步驟：加點單品

用來直接記「某樣食物吃了多少」，例如一碗白飯、一份雞胸肉、一杯牛奶、一個水果。資料來自食物代換表（把食物分成幾大類、每一類的「1 份」營養量固定，是營養師常用的換算方式），所以可以記到半份的精細程度。

  1. 最上面一行小字：「單品不含烹調用油；有用油可以加油脂類。」意思是煮東西用的油不會自己算進去，要的話自己再加一筆油脂。
  2. 已選框之後、搜尋框之前，如果你有標常吃的單品，會有一組「常吃」；已選框每一列在「移除」旁邊有「常吃／取消常吃」。標了以後那樣東西還是選著，只是搬到常吃組。搜尋結果照舊全部列出。
  3. 搜尋框「搜尋單品（名稱或別名）」：打字就即時出結果。找不到會寫「找不到「…」。」搜尋也找得到水果和飲品，這些會多標「在飲品・水果」。清空就回到分類。
  4. 分類：乳品類、豆魚蛋肉類、全穀雜糧類、蔬菜類、油脂與堅果種子類（水果在上面一步），每個類別後面標筆數、預設收著。點開大類看到子類（例如豆魚蛋肉類有水產、家畜、家禽、蛋…），子類也是收著，再點開才看到品項。
  5. 每張卡片：名稱，下面一行「代換表 1 份 · 生重 30g · 約 N kcal」。有些食物對不到代換表，會寫「內建一餐 · 熟重 150g · 約 N kcal」（意思見下面）。灰掉的寫原因（「含過敏原」「成分未確認」「不符合你的飲食設定」「飲食限制未確認」「你標了不吃」）。
  6. 點卡片加進來：已選框長出一列，名稱、「−」份數「＋」、「移除」，下面一行份量說明。
  7. 再點一次已經選了的卡片：不會多加一筆，份數也不變，畫面捲到它的步進器。

你加的「我的食材」（見〈我的食物〉的自煮）會放在每個大類的最後一組「我的食材」，以及「其他食材」。沒設一份的只有克數框，預設 100。

已選的單品有「份」「克」兩個按鈕（液體是「份」「毫升」）。按「克」可以直接輸入實際吃的克數，整數 1 到 3000，打完點旁邊或按完成才生效。份換成克會變成整數克，克換回份會換成最接近的半份。紀錄名稱寫實際的量，例如「白飯 95g」。

最多 4 項

一餐的單品（含家裡的飲品、水果）合計最多 4 項。要加第 5 項時跳出「單品最多選 4 項。」，那一項不會加進去。單品不佔主餐、配菜、飲料的名額，也不影響你在哪個分頁（記錄的型態看你停在超商、外食還是自煮）。

單品卡片上沒有「不吃」按鈕（已選框每一列有「常吃」）；要標單品不吃，到「我的食物」去標，標了之後單品會移到這一步最下面的「你標了不吃」。

份量說明文字怎麼讀

步進器下面那行小字，格式是「N 份＝（狀態）量（家用量）」。例子：

「1 份＝240ml（1杯）」液體寫毫升，不加狀態詞；括號是家用量。
「4 份＝熟重 160g（1碗）」「熟重」是煮熟後的重量；4 份是 1 碗。
「0.5 份＝熟重 20g」半碗的幾分之幾不好讀時，只寫克數、不寫家用量。
「4 份＝可食部分 520g（4個，購買量約 680g）」水果、油脂的生品寫「可食部分」：去掉皮、核之後真正吃進去的重量；「購買量」是買回來還帶皮核時大約多重。
「1 份＝內建一餐 熟重 150g」這個食物對不到代換表的「1 份」，所以 1 份就是今日建議裡「一餐」用的量。份數大於 1 時會寫「4 份＝…（1 份是內建一餐 …）」。
  • 生重：還沒煮的重量。熟重：煮好的重量。乾重、濕重：乾的／泡水或含水的狀態。同一種食物生重和熟重差很多，記的時候看清楚這個字。
  • 家用量（碗、杯、個、片…）會跟著份數一起乘；乘出來湊不成好讀的數字（例如八分之一碗），就不寫家用量，只寫克數或毫升。
  • 「1 份」是代換表固定的營養量，不是一般的「一份」。看克數比看「份」可靠。

紀錄名稱怎麼寫

按「記下這餐」後，那一餐的名稱會自動組出來，用「＋」連起來：

  • 超商／外食品項：名稱（有改份量就帶「×2」或「（半份）」），再接直接估算的名稱，再接單品，最後是現成飲料。
  • 單品寫「量」不寫份數，例如「全脂奶（自己倒） 480ml＋白飯 160g」。生的在量前面加「生」，例如「雞胸肉 生 120g」；乾的加「乾」；熟食、液體不加；水果寫可食部分，不加「生」，例如「柳丁 520g」。
  • 單品照你點的順序排，在現成飲料前面。
  • 自煮：餐型名稱＋食材（蛋白質、主食、蔬菜、醬料的順序）＋單品＋飲料。

畫面底部的摘要與提示怎麼讀

視窗最下面固定三塊，會隨你每次選取更新：

1. 提示一行（有問題才出現）

有這一行時「記下這餐」是淡色按不下去，寫的就是原因。例如「請至少選一個品項。」「請先選餐型」「請選蛋白質」「請選主食」「請選烹調法」「快煮不含「烤／氣炸」，請換成開伙或換掉它。」「單品最多選 4 項。」。排掉原因後這行就消失、按鈕可以按。

2. 摘要（粗體那行）

已選 2 件 · 約 633 kcal · 蛋白質 38g · 碳水 78g · 脂肪 19g · 纖維 5g · 鈉 約 90 mg（部分品項無資料）
  • 「已選 N 件」：品項、直接估算、單品、飲料加起來的件數。自煮有餐型時，這裡改寫成「已配好」或「還沒配好」。
  • 「約 N kcal」：這一餐的總熱量；自煮煎炒會寫「（含用油約 Ng）」。
  • 蛋白質、碳水、脂肪、纖維用公克；「—」代表資料裡沒有這個數字（不知道），不是 0。有估算或自己新增沒填這項的品項，常會看到。
  • 「鈉 約 N mg」；全部都沒資料寫「鈉 無資料」；只有一部分品項有資料時後面加「（部分品項無資料）」，意思是實際的鈉比顯示的高。
  • 自煮溫沙拉最後會有「未含沙拉醬」（見上一段）。

3. 缺口與說明（灰色小字，每行一件事）

「蛋白質缺口約 24g」「纖維缺口約 6.4g」
這一餐在你今天目標裡分到的量，扣掉你現在選的，還差多少。這個「分到的量」會隨你今天已經記了什麼而變。已經夠了就不顯示這行。這只是提醒，不是限制，缺口大也可以記。
「蛋白質：無資料」「纖維：無資料」
選的東西裡有這項不知道的，所以算不出缺口，不當 0 處理。
「這組合約 N kcal，這個時段配額約 N kcal（+N），仍可送出。」
熱量超過這個時段的配額。僅是告知，可以照記；記下之後，其他時段的建議會自動調整。如果這餐含「直接估算」，說法會換成「…先記下來，其他餐會自動調整。」
「超商分頁還有 2 項沒有算進這餐」
你在別的分頁（超商或外食）還留著選取。送出只算目前這個分頁加上共用的飲料與單品，那些沒算進去。見下一段。
「編輯組合不計算時段的配額。」
只出現在編輯組合時（見〈我的組合〉）。

切分頁、取消、記下這餐

切分頁時，其他分頁的選取怎麼辦

  • 超商和外食各自保留自己的選取。切過去再切回來，還在。
  • 自煮的選擇也保留（餐型、食材、烹調法、滑桿）。
  • 共用的部分跟著你走：現成飲料、家裡的飲品與水果、加點單品，三個分頁看到的是同一份。
  • 但記下這餐時，只算「目前這個分頁」加上共用的飲料與單品。別的分頁選的東西不會被記下來。超商或外食還有選取時，摘要下面會多一行「超商分頁還有 N 項沒有算進這餐」提醒你（自煮分頁的選擇沒有這行提醒）。想把它們也算進去，要切過去把這一餐記下，另外再記一次。
  • 記下的型態＝你按「記下這餐」當下停在的分頁（超商、外食、快煮或開伙）。

記下這餐、取消

  • 「記下這餐」：視窗關閉，那個時段變成「已記錄：…」，並記住這次的分頁（下次「無偏好」的時段會停在這頁）。
  • 「取消」或點視窗外的灰色區域：視窗關閉，這一餐沒有記，選的東西全部丟掉；再打開會回到預設分頁。
  • 在視窗裡做的「不吃」「新增品項」「複製成我的版本」是立刻存起來的，取消也不會復原；今日建議會因為「不吃」馬上重新整理。

我的組合

常吃的一餐（例如「平日午餐：健身餐盒＋全脂奶」）存成組合，下次在「自己選」最上面點一下，就把整餐帶進來，不用重選。組合只存「選了哪些東西、份量多少」；熱量與營養每次都用目前的資料重算。今日建議的推薦不會用到組合。

存成組合：兩個入口

入口 1：記的時候順便存

  1. 在「自己選」選好要吃的。
  2. 捲到最下面（共用步驟後面），勾「存成組合（下次在「自己選」最上面一點就帶入）」。
  3. 出現名稱欄，自動填好品名（用「＋」連起來，不寫份量，最多 40 字），可以改。選取一變、而你還沒改過名稱，名稱會跟著更新。
  4. 按「記下這餐」：這一餐記下來，組合也同時存好。取消勾選就只記這一餐。
  • 名稱空白時會提示「請填組合名稱。」
  • 有「直接估算」的一餐不能存：勾選框是灰的，寫「估算的一餐不能存成組合。」
  • 有東西不能存（例如被你的過敏原擋掉）會提示「不能存成組合：…。取消勾選「存成組合」就只記這一餐。」
  • 存下的內容：型態（超商／外食／快煮／開伙）、品項與各自的份量（半份到 ×2、單品的份數）、飲料；自煮的話是餐型、食材、烹調法。用油與調味只有你在這次改過才會存，沒改過就是每次用當下的預設。自煮的份量滑桿不存，帶入後回到 1.0 倍。

入口 2：記完之後在今日建議存

  1. 在「今日建議」已記錄的卡片，按「撤銷」旁邊的「存成組合」。
  2. 名稱欄預填品名，改好後按「存」（或「取消」）。
  3. 成功寫「已存成組合「…」，在「自己選」最上面。」如果其中有品項已經不提供，會一併寫「以下品項已不提供，沒有存進組合：…」。

這個入口一律不保留用油與調味；只有今天的紀錄才有這個按鈕；含「直接估算」的紀錄沒有。

在「自己選」裡用組合

  • 存過組合後，視窗最上面（不管停在哪個分頁）多一列「我的組合（點了帶入，可以再改）」，卡片可以左右滑。沒有組合時這一列不會出現。
  • 每張卡片：組合名稱、「超商 · 約 N kcal」（型態與帶入後的熱量），名稱跟內容不同時多一行品名。
  • 點卡片＝帶入：自動切到那個組合的分頁，把品項、份量、飲料、單品選好，上方寫「已帶入「名稱」。」。帶入只取代那個分頁的選取與共用的飲料、單品；其他分頁原本的選取保留。帶入後還可以再改、再記。
  • 帶入的品項如果這個時段平常不會列出，那一項下面會註明「從我的組合帶入（這個時段平常不列出）」。

有項目不能用的時候

帶入時，組合裡的項目如果現在不能用，卡片會寫「有 N 項目前不能用：原因」，帶入時不會預選那幾項，並在上方說明原因，其他項目照常帶入。原因可能是：你勾了過敏原、你標了不吃、已經不提供（下架）、這個時段的主餐已經超過上限（例如午餐 2 個，下午茶只能 1 個）、單品超過 4 項。整個組合都不能用，卡片就灰掉不能點。

特別的情況：如果組合裡的內建品項後來被你「複製成我的版本」，組合會自動改用你的版本。

每個子分頁都有的操作

下面這幾段，在上面任何一個子分頁都一樣。

點一列看明細

點一列展開明細，再點一次收起來；一次只開一筆，被擋的也可以點開看原因。明細內容：

  • 「一份：」熱量；蛋白質、碳水、脂肪、纖維；飽和脂肪與「鈉 約 N mg（參考 2400 mg）」（2400 只是參考線，沒有顏色與警告）；沒資料的寫「無資料」。
  • 「過敏原：」已知的列出來，還有沒確認的會寫「其他成分未確認」；「飲食宣告：」全素、蛋奶素或「沒有宣告全素或蛋奶素」。
  • 「品牌／分類：」「能在哪些餐出現：」（飲料寫「飲料任何時段都能選」）。
  • 「出處：」依類別分組，例如「熱量、蛋白質…：估算」；衛福部的附整合編號，例如「衛福部（整合編號 …）」。代換表的食材另有「1 份（代換表）＝生重 30g」「今日建議的一餐：生重 130g（約 4.5 份代換表）」、含糖果乾「衛福部樣品：有加糖」、一些說明文字，以及「由生米推算，可能略高估」「…以 0 計」這類資料處理的說明。
  • 被擋住的品項會寫「以你目前的設定：你設了過敏原「蛋」，…」。
  • 按鈕列，第一個是「常吃」（標了變「取消常吃」）。內建超商／外食品項是「常吃、複製成我的版本、不吃」；自煮與飲品・水果的代換表品項是「常吃、不吃」；我的品項是「常吃、編輯…刪除」（刪除的沒有常吃）。被擋的也可以複製。

標「常吃」

  1. 點開品項，按「常吃」。
  2. 它搬到子分頁最上面的「常吃（N）」（不收合），上方寫「已標常吃「…」，自己選會放在最上面。」想取消，按「取消常吃」。
  • 超商、外食、自煮、飲品・水果四個子分頁最上面各有一組「常吃（N）」。常吃的東西搬過去，原本的分類裡不再出現，每樣只出現一次。組內順序：現成品項 → 代換表品項 → 我的品項。搜尋結果的狀態會寫「常吃」。
  • 被過敏原或飲食限制擋住的常吃：留在常吃組，灰在組的最後。
  • 常吃只影響「自己選」和這裡的排列，今日建議的推薦不受影響。數量不限。
  • 同一樣東西不能同時是常吃和不吃：標常吃會自動取消不吃，訊息補「原本標的不吃已取消。」；標不吃會自動取消常吃，訊息補「原本標的常吃已取消。」
  • 內建品項是常吃時按「複製成我的版本」，常吃會換成你的版本（原品項收進「已換成我的版本」）。
  • 備份會帶著常吃清單。

標「不吃」

  1. 點開品項，按「不吃」。
  2. 它移到子分頁最下面收起來的「你標了不吃」，畫面自動捲到那裡；上方寫「已標不吃「…」。」後接一句說明：一般品項寫「推薦與「自己選」都不會再選它」，單品類寫「只擋這一項，不影響推薦裡的其他食物」。
  3. 到「自己選」或推薦，它就不會出現（單品在「你標了不吃」那一組、灰掉）。
  4. 如果它原本是常吃，標不吃會自動取消常吃，上方訊息補「原本標的常吃已取消。」
  5. 想取消：按「取消不吃」，回到原位。「今日建議」卡片上「順便不要」標的食材，也在這裡（最下面「你標了不吃的全部」）取消。
  • 同一個食物的其他形式：有些食材在 App 裡有好幾筆，其實是同一個衛福部樣品（例如白米與白粥（稠），或「全脂奶（自己倒）」與外帶的「鮮奶（一杯，約240ml，全脂）」）。明細會寫「同一種食材的其他形式：…」或「同一個衛福部樣品：…」。標了其中一個不吃之後，明細會出現「也標不吃「…」」按鈕，一鍵把另一個也標掉；取消時有「也取消「…」」。不按的話，只擋你標的那一項。
  • 「你標了不吃的全部（N）」：列出所有標過不吃的，各有「取消不吃」。已經下架、查不到的寫「（已不提供）」，按鈕改成「移除」。各子分頁的「你標了不吃」只算那個分類，所以筆數可能比「全部」少。

我的品項（你自己新增的）

  • 新增：子分頁最下面「＋新增到我的…品項」。表單比「自己選」裡的快速新增完整：名稱、熱量、「在哪裡買」（超商／外食）、「角色」、「適合的時段」（至少勾一個）、「過敏原」、「更多（選填）」。存成功寫「已新增「…」。」如果角色讓它屬於別的子分頁，會告訴你「它在「…」的我的品項」。
  • 複製成我的版本：在內建品項明細按。存完原品項會換成你的版本，上方寫「已複製成我的版本「…」。原本的內建品項已換成你的版本，可以在「已換成我的版本」改回內建。」複製來的品項列上寫「從內建複製」，點開明細有「內建目前的數值」，方便對照；內建已經下架的話寫「內建已不提供這個品項。」
  • 編輯／補填：我的品項明細按「編輯」；被擋（成分未確認等）的有「補填」。
  • 刪除／還原：明細按「刪除」，移到「已刪除（N）」，打開後點那筆按「還原」。刪除複製品時，如果原本的內建品項還是換成你的版本，會提醒「原本的內建品項「…」仍是換成你的版本，要用回內建到「已換成我的版本」按「改回內建」。」
  • 已換成我的版本：複製後換掉的內建品項在這裡，按「改回內建」用回原本的；如果你還有複製品，會寫「你有一筆從它複製的我的品項「…」。」
  • 狀態只用灰色文字表示（「成分未確認」「含過敏原」「不符合你的飲食設定」「飲食限制未確認」），不上色。

本週總覽

這一頁是做什麼的：看這一週整體吃得怎麼樣。刻意只給「週平均有沒有在目標內」的中性說明，不逐天打分數。

畫面上有哪些區塊

本週摘要（四行）
  • 熱量：例如「本週平均熱量在目標範圍內（3 個完整記錄日平均 N／目標 N kcal）」。平均與目標差在 5% 以內寫「在目標範圍內」，高於寫「高於目標」，低於寫「低於目標」。
  • 蛋白質、膳食纖維：「週平均 N g／目標 N g（達成率 N%）」。
  • 最後一行「近7天平均 N／目標 N kcal」（不含今天；資料不夠寫「近7天平均：資料不足」）。
每日紀錄
本週從週一到今天，每天一行「週一 10/05　N kcal」；沒記的寫「尚無紀錄」。整週都沒有時寫「本週尚無紀錄」。

什麼叫「完整記錄日」

週平均只算「完整記錄的日子」：當天所有開啟的時段都有記錄才算，而且今天不算（今天還沒過完）。還沒有這樣的日子時，摘要寫「本週還沒有完整記錄的日子（當天所有開啟時段都有記錄才算，今天不算）」。

蛋白質、纖維的平均只算「有這項資料」的完整記錄日；有些日子因為品項沒有資料沒算進去時，後面會註明，例如「（4 天有資料）」。整週都沒有資料寫「—（完整記錄日的紀錄都沒有這項資料）」。吃了熱量只知道、沒有纖維資料的東西（例如部分加工肉品），就會這樣。

補記過去的一餐

在「每日紀錄」上面有「補記過去的一餐」。想把過去某一餐補上去，不是昨天的話，用這裡。最多回推 7 天，不含今天（今天的請到「今日建議」）。

  1. 「日期」欄選一天，預設是昨天。
  2. 按那一餐的按鈕（早餐、午餐…，只列你在「基本資料」開著的時段）。
  3. 跳出「自己選」視窗，標題寫「補記 10/03（週六）：晚餐」，按鈕是「補記這餐」。
  4. 選法跟平常一樣。不確定吃了什麼，可以用外食的「找不到？直接估算」；家裡的共餐、外食的「自助餐」也都能用。
  5. 按「補記這餐」，那一天就多一筆紀錄，上面的每日紀錄與週平均跟著更新。
  • 視窗裡寫「補記過去的一餐，不計算配額」，不會動到那一天的配額。
  • 選了超出範圍的日期，會提示「請選過去 7 天內的日期（不含今天，今天的請到今日建議）。」

運動紀錄

這一頁是做什麼的：記你做了什麼運動、多久、強不強。只記項目、時長、強度，不換算熱量，也不影響今日建議的飲食熱量；整頁看不到任何飲食數字。

畫面上有哪些區塊

  • 連續紀錄：寫「連續紀錄 N 天」或「尚未開始連續紀錄」。從今天往回數，每天都至少有一筆才算；今天還沒記不算中斷（從昨天起算）。
  • 本週活動量參考：例如「本週已活動 90 分鐘（目標 150 分鐘）・肌力訓練 1 天（目標 2 天）」，下面註明是 WHO 一般性建議、僅供參考。
    • 中強度的分鐘照算，高強度的分鐘算兩倍。
    • 低強度不計入 150 分鐘，另外寫「另有輕度活動 N 分鐘」。
    • 「重訓」不算分鐘，算「肌力訓練」的天數（同一天多筆只算一天）。
  • 新增運動記錄：日期（預設今天）、運動項目、時長（分鐘）、強度、「記錄」。
  • 歷史紀錄：新到舊，每筆「項目　日期 · N 分鐘 · 低／中／高強度」。沒有時寫「尚無運動紀錄」。

常見操作

  1. 選日期。
  2. 選運動項目：散步、快走、慢跑、腳踏車、游泳、羽毛球、籃球、重訓、瑜伽，或「其他（自行輸入）」（會多出「自訂運動項目」欄，例如「爬山」）。
  3. 強度會跟著項目自動帶一個常見的值（例如散步＝低、慢跑＝高），你可以自己改。你手動改過強度之後，再換項目就不會再被改掉。
  4. 填時長（分鐘），按「記錄」。歷史紀錄多一筆，本週活動量更新。

看到這些字是什麼意思（速查）

灰掉的品項上的字

「含過敏原」
含有你勾的過敏原。
「成分未確認」
你勾了過敏原，這項成分沒逐項確認過，所以避開。自己新增的可以用「補填」。
「飲食限制未確認」
你設了蛋奶素或全素，這項沒有宣告符合。
「不符合你的飲食設定」
食物代換表的品項（已人工確認過素不素）不符合你的飲食型態，例如蛋奶素看到雞胸肉。
「你標了不吃」
你自己標了不吃。按「取消不吃」放回來。
「常吃（N）」
你標了常吃的東西，放在最上面一組，原本的分類裡不再出現。只影響排列，不影響今日建議的推薦。
「你已設定不吃：雞胸肉」
自煮選項灰掉的原因：這個食材在你的不吃清單裡。

自煮選項灰掉的原因

「快煮不含這個食材」「快煮不含這個烹調法」
目前選的是快煮，這一項太費工。切到「開伙」就能選。
「最多選 2 個」「最多選 3 個」
蛋白質最多 2、蔬菜最多 3，已經選滿。
「這個食材需要加熱」「已選的食材需要加熱」
烹調法選了「免開火／免烹調」，不能搭配需要加熱的食材。

摘要與提示

「—」或「無資料」
資料裡沒有這個數字，不是 0。
「（部分品項無資料）」
選的東西裡有幾樣沒有這項資料，實際值比顯示的高。
「已配好」「還沒配好」
自煮的餐型有沒有配完整。
「未含沙拉醬」
沙拉醬的熱量沒算進去。
「（含用油約 10g）」
煎、炒用的油已經算進熱量。
「N 項因設定不能選」
一整組都被你的過敏原或飲食設定擋住，收成一行。
「超商分頁還有 N 項沒有算進這餐」
別的分頁的選取，沒有記到這一餐。
「蛋白質缺口約 Ng」「纖維缺口約 Ng」
這一餐在今天目標裡分到的量，還差多少。提醒而已。
「+N」（配額後面）
超過這個時段配額的 kcal，仍可記，其他餐會自動調整。

份量說明

「生重」「熟重」「乾重」「濕重」
食物在哪個狀態下量的重量。
「可食部分」「購買量」
水果、油脂的生品：去掉皮核後吃的量／買回來帶皮核時的量。
「內建一餐」
沒有對應代換表「1 份」的食物，1 份＝今日建議用的一餐的量。
「代換表 1 份」
食物代換表裡固定營養量的一份。

其他

「已不提供」
這個品項已經從 App 內建資料拿掉。在不吃清單裡可以按「移除」；組合裡會寫在不能用的原因。
「從我的組合帶入（這個時段平常不列出）」
這個品項平常在這個時段不會出現，是組合把它帶進來的。
「今天這個來源沒有合適的選擇，已改為一般推薦」
你設的來源偏好今天找不到合適的，改用一般挑法。
「共餐」
自煮分頁（開伙、午餐與晚餐）「選餐型」那排最後的選項，從當季家常菜選 1 到 4 樣，記你自己吃的那一份，數字是估計。跟餐型擇一。
「自助餐」
外食分頁最上面的卡，依主食、菜的道數與類別、菜量、湯估算一餐，數字是估計。
「當季」「非當季」
共餐的家常菜只列當季的。已選但後來不是當季的菜標「非當季」，可以取消。
「預約 · 約 N kcal」
先排好的一餐。按「記下」才算吃過；可以「改」或「取消預約」。排預約不計算配額。
「這餐不吃」「這餐沒吃」
按了這餐記成 0 大卡，卡片寫「這餐沒吃」，可以撤銷。不確定有沒有吃就不要按。
「補記這餐」
補上過去 7 天內的一餐（在「本週總覽」），不計算配額。
「昨天的餐（N 餐）」
今日建議最上面收起來的卡，隔天用來確認昨天的餐。「不確定」只是收起，不寫紀錄。
